\chapter{Quick Start Guide}
\label{ch:quickstart}
%======================================================

This chapter provides a step-by-step guide to using the integrated Source Extractor in DS9. For detailed explanations of the extraction algorithm, output parameters, and internal architecture, refer to the subsequent chapters.

\section{Overview}

The DS9 Integrated Source Extractor adds SExtractor-like source detection and photometry capabilities directly within the OGFinder image viewer. When a FITS image is loaded, sources can be extracted with a single click, and the resulting catalog is displayed in a resizable panel alongside the image.

Key features:
\begin{itemize}[leftmargin=2em]
  \item \textbf{One-click extraction} --- Press the ``Extract'' button to detect and measure all sources in the current FITS image
  \item \textbf{Split-panel interface} --- The main window is divided into an image viewer (left) and a catalog table (right), separated by a draggable divider
  \item \textbf{19 output parameters} --- Photometry, astrometry, morphology, surface brightness, and star/galaxy classification
  \item \textbf{Real-time filtering} --- Filter the catalog interactively by any column value
  \item \textbf{Automatic WCS} --- Celestial coordinates (RA, Dec) are computed automatically when WCS information is available in the FITS header
  \item \textbf{Auto-extraction} --- Sources are extracted automatically when a new FITS file is loaded
\end{itemize}

\begin{figure}[htbp]
  \centering
  \includegraphics[width=\textwidth]{ogfinder_init.png}
  \caption{OGFinder initial screen.  The split-panel interface shows the image viewer (left) and the catalog table (right).  The title bar contains the custom menus: SExtractor, Display, AI~Merge, Galaxy~Model, Star(PSF), Deconvolution, Separate, ICL, and LSBG.}
  \label{fig:ogfinder-init}

\section{Prerequisites}

\begin{itemize}[leftmargin=2em]
  \item \textbf{DS9} --- OGFinder built with the integrated Source Extractor patch
  \item \textbf{Python 3} with the following packages:
  \begin{itemize}
    \item \texttt{sep} --- Source Extraction and Photometry library (Python binding of SExtractor)
    \item \texttt{astropy} --- FITS I/O and WCS coordinate transformations
    \item \texttt{numpy} --- Numerical array operations
  \end{itemize}
  \item \textbf{\sextract{} binary} --- The compiled Python script, located in the same directory as the \ds{} executable
\end{itemize}

\begin{codebox}[Install Python Dependencies]
\begin{lstlisting}[style=bash,numbers=none]
pip install sep astropy numpy
\end{lstlisting}
\end{codebox}

\section{Building DS9 with the Source Extractor}

\begin{codebox}[Build Commands]
\begin{lstlisting}[style=bash,numbers=none]
cd OGFinder
make -C ds9/unix -j 128
\end{lstlisting}
\end{codebox}

The build process compiles the C/Tcl core, packages the Tcl library files (including the modified \texttt{layout.tcl} and \texttt{ds9.tcl}) into \texttt{ds9.zip}, and produces the final \texttt{bin/ds9} executable. The \sextract{} binary must be placed in the same \texttt{bin/} directory.

\begin{important}
After modifying any \texttt{.tcl} file in \texttt{ds9/library/}, you must copy it to \texttt{ds9/unix/mntpt/library/}, update the zip, and rebuild:
\begin{codebox}
\begin{lstlisting}[style=bash,numbers=none]
cp ds9/library/layout.tcl ds9/unix/mntpt/library/
cp ds9/library/ds9.tcl    ds9/unix/mntpt/library/
cd ds9/unix
zip -ru ds9.zip mntpt/library/layout.tcl mntpt/library/ds9.tcl
cat ds9base ds9.zip > ds9
zip -A ds9
chmod 755 ds9
cp ds9 ../../bin/
\end{lstlisting}
\end{codebox}
\end{important}

\section{Using the Source Extractor}

\subsection{Step 1: Launch DS9}

\begin{codebox}[Launch]
\begin{lstlisting}[style=bash,numbers=none]
./bin/ds9 image.fits
\end{lstlisting}
\end{codebox}

The window opens with two panels separated by a vertical divider:
\begin{itemize}[leftmargin=2em]
  \item \textbf{Left panel} --- The standard DS9 interface (menu bar, info panel, buttons, image canvas, colorbar)
  \item \textbf{Right panel} --- The Source Extractor catalog panel (title bar, filter bar, data table, status bar)
\end{itemize}

The divider can be dragged left or right to resize the panels.

\subsection{Step 2: Extract Sources}

Click the \textbf{``Extract''} button in the catalog panel title bar. The status bar will show progress:
\begin{enumerate}[leftmargin=2em]
  \item \texttt{Extracting sources from image.fits ...} --- Extraction is running
  \item \texttt{image.fits: 142 sources extracted} --- Extraction complete
\end{enumerate}

The catalog table is automatically populated with all detected sources, sorted by brightness (brightest first).

\begin{infobox}[Auto-Extraction]
When a FITS file is loaded via \texttt{File $\to$ Open}, sources are extracted automatically after a 500\,ms delay. This behavior is controlled by the \texttt{CatalogPanelAutoExtract} hook in \texttt{fits.tcl}.
\end{infobox}

\subsection{Step 3: Browse the Catalog}

The catalog table displays 19 columns (see Chapter~\ref{ch:parameters} for detailed descriptions):

\begin{center}
\begin{tabular}{ll}
\toprule
\textbf{Category} & \textbf{Columns} \\
\midrule
Identification & NUMBER \\
Astrometry & X\_IMAGE, Y\_IMAGE, ALPHA\_J2000, DELTA\_J2000 \\
Photometry & MAG\_AUTO, MAG\_ISOCOR, MAG\_APER, FLUX\_AUTO \\
Morphology & FLUX\_RADIUS, A\_IMAGE, B\_IMAGE, THETA\_IMAGE, ELLIPTICITY \\
 & KRON\_RADIUS \\
Surface Brightness & MU\_MAX, MU\_THRESHOLD \\
Classification & CLASS\_STAR, FLAGS \\
\bottomrule
\end{tabular}
\end{center}

\begin{itemize}[leftmargin=2em]
  \item Scroll horizontally and vertically using the scrollbars
  \item Column widths can be resized by dragging column borders in the header row
  \item Rows can be selected by clicking (extended selection with Shift/Ctrl)
\end{itemize}

\subsection{Step 4: Filter Results}

Type a search pattern in the \textbf{Filter} entry and click \textbf{``Apply''} (or press Enter). The filter performs case-insensitive substring matching across all columns. For example:
\begin{itemize}[leftmargin=2em]
  \item Type \texttt{0.9} to show only rows containing ``0.9'' in any field
  \item Clear the filter field and press Apply to show all sources again
\end{itemize}

\subsection{Step 5: Clear and Re-extract}

Click \textbf{``Clear''} to reset the table and status. Load a new FITS image and click \textbf{``Extract''} again, or rely on auto-extraction.

\chapter{Architecture}
\label{ch:architecture}
%======================================================

This chapter describes the internal architecture of the integrated Source Extractor, covering the modified DS9 source files, the extraction pipeline, and the data flow between components.

\section{Modified Source Files}

Three files implement the integration:

\begin{center}
\begin{longtable}{L{4.2cm} L{8.8cm}}
\toprule
\textbf{File} & \textbf{Role} \\
\midrule
\endhead
\texttt{ds9/library/ds9.tcl} & Creates the top-level \texttt{ttk::panedwindow} that splits the main window into two panes. Initializes \texttt{ds9(toppw)}, \texttt{ds9(main)}, and \texttt{ds9(catalog\_frame)}. Calls \texttt{CreateCatalogPanel}. \\
\midrule
\texttt{ds9/library/layout.tcl} & Defines \texttt{CreateCanvas} (image canvas, restored to original structure), \texttt{CreateCatalogPanel} (catalog UI), \texttt{CatalogPanelExtract} (runs \sextract{}), \texttt{CatalogPanelLoadTSV} (parses output into table), \texttt{CatalogPanelFilter} (interactive filtering), and \texttt{CatalogPanelAutoExtract} (auto-extraction hook). \\
\midrule
\texttt{ds9/library/fits.tcl} & Calls \texttt{CatalogPanelAutoExtract} after a FITS file is loaded, triggering automatic source extraction. \\
\bottomrule
\end{longtable}
\end{center}

\section{Top-Level Window Structure}

The key architectural change is the introduction of a \texttt{ttk::panedwindow} at the highest level of the widget hierarchy, directly below the native pulldown menu bar.

\begin{codebox}[ds9.tcl --- Top-level panedwindow creation]
\begin{lstlisting}[style=tcl,numbers=none]
# create top-level panedwindow
set ds9(toppw) [ttk::panedwindow ${ds9(top)}pw -orient horizontal]
pack $ds9(toppw) -fill both -expand true

# left pane: main DS9 content
set ds9(main) [ttk::frame ${ds9(top)}ds9]
$ds9(toppw) add $ds9(main) -weight 3

# right pane: catalog panel
set ds9(catalog_frame) [ttk::frame ${ds9(top)}catf]
$ds9(toppw) add $ds9(catalog_frame) -weight 2
\end{lstlisting}
\end{codebox}

This design ensures that:
\begin{enumerate}[leftmargin=2em]
  \item The pulldown menu bar spans the full window width (it is set via \texttt{\$ds9(top) configure -menu \$ds9(mb)}, independent of pack geometry)
  \item Everything below the menu bar is split into two resizable panes
  \item All existing DS9 layout modes (horizontal, vertical, basic, advanced) continue to work within the left pane without modification
  \item The catalog panel occupies its own independent pane on the right
\end{enumerate}

\section{Data Flow}

The extraction pipeline follows this sequence:

\begin{enumerate}[leftmargin=2em]
  \item \textbf{Trigger} --- User clicks ``Extract'' (or auto-extraction fires after FITS load)
  \item \textbf{File discovery} --- \texttt{CatalogPanelExtract} retrieves the current FITS filename from the active frame via \texttt{\$current(frame) get fits file name full}
  \item \textbf{External process} --- The \sextract{} binary is executed as a child process via \texttt{exec sh -c}. The \texttt{LD\_LIBRARY\_PATH} is configured to include conda library paths.
  \item \textbf{Output capture} --- \sextract{} writes a tab-separated table to \texttt{stdout}. The Tcl \texttt{exec} command captures this output as a string.
  \item \textbf{Table population} --- \texttt{CatalogPanelLoadTSV} parses the TSV string, splits it into rows and columns, and populates the \texttt{Tktable} widget via the \texttt{catpaneltbldb} array variable.
  \item \textbf{Status update} --- The status bar displays the filename and number of detected sources.
\end{enumerate}

\begin{remark}[Process Isolation]
The extraction runs as a separate process, not within the DS9 Tcl interpreter. This prevents numerical library conflicts and allows the Python-based extractor to use its own dependencies (NumPy, SEP, Astropy) independently.
\end{remark}


%======================================================
\chapter{Extraction Algorithm}
\label{ch:algorithm}
%======================================================

The \sextract{} tool implements a SExtractor-compatible extraction pipeline using the SEP (Source Extraction and Photometry) library. This chapter describes each step of the algorithm in detail.

\section{Background Estimation}

The first step is to estimate and subtract the sky background. SEP uses the same algorithm as SExtractor:

\begin{enumerate}[leftmargin=2em]
  \item The image is divided into a grid of rectangular meshes (default size: $64 \times 64$ pixels, controlled by \texttt{--back-size})
  \item In each mesh cell, the local background level is estimated using iterative $\kappa\sigma$-clipping
  \item The resulting coarse background map is smoothed with a median filter (default kernel: $3 \times 3$ cells, controlled by \texttt{--back-filtersize})
  \item The smoothed map is interpolated to full image resolution using bicubic spline interpolation
\end{enumerate}

\begin{codebox}[Background estimation]
\begin{lstlisting}[style=python,numbers=none]
bkg = sep.Background(data, bw=back_size, bh=back_size,
                     fw=back_filtersize, fh=back_filtersize)
data_sub = data - bkg.back()
\end{lstlisting}
\end{codebox}

Two outputs are produced:
\begin{itemize}[leftmargin=2em]
  \item \texttt{bkg.back()} --- the background level map $B(x,y)$
  \item \texttt{bkg.rms()} --- the background RMS (noise) map $\sigma_B(x,y)$, used as the detection threshold and photometric error
\end{itemize}

\section{Source Detection}

Sources are detected as groups of connected pixels above a threshold:

\begin{equation}
I(x,y) - B(x,y) > k \cdot \sigma_B(x,y)
\end{equation}

where $k$ is the detection threshold in units of the local background RMS (default: $k = 1.5$, set by \texttt{--detect-thresh}). Connected pixel groups with fewer than \texttt{--detect-minarea} pixels (default: 5) are rejected.

\subsection{Observation Boundary Masking}
\label{subsec:mask}

Many astronomical images---particularly JWST and HST mosaics---contain regions outside the actual observation footprint that are filled with zero-valued pixels. Without masking, \sep{} may detect spurious sources at the boundary between the observed and unobserved regions, where the sharp transition from zero to real flux mimics a source profile.

\sextract{} automatically constructs a \textbf{pixel mask} from the original FITS data before any processing:

\begin{equation}
M(x,y) = \begin{cases}
1 & \text{if } I_{\mathrm{raw}}(x,y) = 0, \; \mathrm{NaN}, \; \text{or} \; \pm\infty \\
0 & \text{otherwise}
\end{cases}
\end{equation}

This mask is passed to \sep{} via the \texttt{sep\_image.mask} field, which excludes masked pixels from both \textbf{background estimation} and \textbf{source detection}. This prevents the zero-filled regions from biasing the local background model and eliminates most false detections at the observation boundary.

\subsubsection*{Boundary Overlap Filtering}

After source detection and measurement, a second filter removes any source whose \textbf{isophotal footprint} overlaps with the mask. For each source, the isophotal ellipse is defined by:

\begin{itemize}[leftmargin=2em]
  \item Semi-major axis: \texttt{ISO\_RADIUS}
  \item Axis ratio: $b/a$ from \texttt{B\_IMAGE} / \texttt{A\_IMAGE}
  \item Position angle: \texttt{THETA\_IMAGE}
\end{itemize}

Every pixel inside this ellipse is checked against the mask. If any masked pixel falls within the isophotal ellipse, the source is excluded from the output catalog. This ensures that partially observed sources at the observation boundary---which would have unreliable photometry and morphology---are not included in the final catalog.

The number of filtered sources is reported to \texttt{stderr}:
\begin{verbatim}
Masked 5765432 / 27562500 pixels (outside observation)
Filtered: 342 / 7204 sources outside observation boundary
\end{verbatim}

\subsection{Deblending}

Overlapping sources are separated using multi-threshold deblending:

\begin{enumerate}[leftmargin=2em]
  \item The detected object is re-thresholded at \texttt{--deblend-nthresh} (default: 32) exponentially spaced sub-thresholds between the detection threshold and the peak value
  \item At each sub-threshold, connected components are identified
  \item A component is split into a separate object if it contains more than \texttt{--deblend-mincont} (default: 0.005) of the total flux of the parent object
\end{enumerate}

\begin{codebox}[Source detection with deblending]
\begin{lstlisting}[style=python,numbers=none]
objects, segmap = sep.extract(
    data_sub, detect_thresh, err=bkg_rms,
    minarea=detect_minarea,
    deblend_nthresh=deblend_nthresh,
    deblend_cont=deblend_mincont,
    segmentation_map=True
)
\end{lstlisting}
\end{codebox}

The segmentation map assigns each pixel to the object it belongs to (or zero for background), enabling morphological measurements.


\section{Photometry}

Three photometric methods are applied to each detected source.

\subsection{AUTO Photometry (Kron Elliptical Aperture)}

The AUTO magnitude follows the Kron (1980) method:

\begin{enumerate}[leftmargin=2em]
  \item The first-moment radius (Kron radius $r_K$) is computed within an ellipse of semi-major axis $6a$:
  \begin{equation}
    r_K = \frac{\sum_i r_i \, I_i}{\sum_i I_i}
  \end{equation}
  where $r_i$ is the elliptical distance of pixel $i$ from the object center, and $I_i$ is the background-subtracted intensity.
  \item A minimum Kron radius of 3.5 pixels is enforced to prevent underestimation for compact sources.
  \item The flux is summed within an elliptical aperture of semi-major axis $2.5 \, r_K$, following the SExtractor convention.
\end{enumerate}

\begin{infobox}[Kron Factor]
The factor of 2.5 applied to the Kron radius ensures that ${\gtrsim}96\%$ of the total flux is captured for a typical galaxy profile (S\'{e}rsic $n \approx 1$--4), while ${\gtrsim}99\%$ is captured for a Gaussian PSF.
\end{infobox}

\subsection{Isophotal Corrected Photometry}

The isophotal flux is the sum of all pixels belonging to the detection footprint. A correction factor accounts for the flux missed below the detection isophote, using the SExtractor formula:

\begin{equation}
F_{\text{isocor}} = \frac{F_{\text{iso}}}{1 - 0.196\,\alpha - 0.751\,\alpha^2}, \qquad
\alpha = \frac{N_{\text{pix}} \cdot t_{\text{local}}}{F_{\text{iso}}}
\end{equation}

where $N_{\text{pix}}$ is the number of detection pixels, $t_{\text{local}}$ is the local threshold, and $F_{\text{iso}}$ is the raw isophotal flux.

\subsection{Aperture Photometry}

A fixed circular aperture of diameter \texttt{--phot-aperture} (default: 5.0 pixels) is centered on each source. The flux is summed within this circle, with partial pixel weighting at the boundary.

\subsection{Magnitude Conversion}

All fluxes are converted to magnitudes using:
\begin{equation}
m = -2.5 \log_{10}(F) + m_0
\end{equation}

where $m_0$ is the magnitude zero-point (default: 25.0, set by \texttt{--mag-zeropoint}). Sources with non-positive flux are assigned $m = 99.0$.


\section{Morphological Parameters}

\subsection{Shape Parameters}

The semi-major axis ($a$), semi-minor axis ($b$), and position angle ($\theta$) are derived from the second-order moments of the intensity distribution within the detection isophote:

\begin{align}
\overline{x^2} &= \frac{\sum_i I_i \, x_i^2}{\sum_i I_i} - \bar{x}^2 \\
\overline{y^2} &= \frac{\sum_i I_i \, y_i^2}{\sum_i I_i} - \bar{y}^2 \\
\overline{xy}  &= \frac{\sum_i I_i \, x_i \, y_i}{\sum_i I_i} - \bar{x}\bar{y}
\end{align}

The ellipse parameters are:
\begin{align}
a^2 &= \frac{\overline{x^2} + \overline{y^2}}{2} + \sqrt{\left(\frac{\overline{x^2} - \overline{y^2}}{2}\right)^2 + \overline{xy}^2} \\
b^2 &= \frac{\overline{x^2} + \overline{y^2}}{2} - \sqrt{\left(\frac{\overline{x^2} - \overline{y^2}}{2}\right)^2 + \overline{xy}^2} \\
\theta &= \frac{1}{2}\arctan\!\left(\frac{2\,\overline{xy}}{\overline{x^2} - \overline{y^2}}\right)
\end{align}

The ellipticity is defined as:
\begin{equation}
e = 1 - \frac{b}{a}
\end{equation}

\subsection{Half-Light Radius}

The half-light radius (\texttt{FLUX\_RADIUS}) is the radius of a circular aperture centered on the source that encloses 50\% of the AUTO flux. It is computed by integrating the flux profile outward from the center until the cumulative flux reaches $0.5 \times F_{\text{AUTO}}$.

\section{Surface Brightness}

Two surface brightness measurements are provided:

\begin{itemize}[leftmargin=2em]
  \item \textbf{MU\_MAX} --- Surface brightness of the brightest pixel:
  \begin{equation}
    \mu_{\max} = -2.5\log_{10}\!\left(\frac{I_{\text{peak}}}{\Omega_{\text{pix}}}\right) + m_0
  \end{equation}
  where $I_{\text{peak}}$ is the peak pixel value above background and $\Omega_{\text{pix}}$ is the pixel area in arcsec$^2$.

  \item \textbf{MU\_THRESHOLD} --- Surface brightness at the detection threshold:
  \begin{equation}
    \mu_{\text{thresh}} = -2.5\log_{10}\!\left(\frac{t_{\text{local}}}{\Omega_{\text{pix}}}\right) + m_0
  \end{equation}
\end{itemize}


\section{Star/Galaxy Classification}

An approximate star/galaxy classifier is implemented using the ratio of the measured FWHM to the seeing FWHM:

\begin{equation}
\text{FWHM}_{\text{image}} = 2\sqrt{\ln 2 \cdot (a^2 + b^2)}
\end{equation}

\begin{equation}
\text{CLASS\_STAR} = \frac{1}{1 + \exp\!\bigl(3 \cdot (r_{\text{FWHM}} - 1.5)\bigr)}, \qquad
r_{\text{FWHM}} = \frac{\text{FWHM}_{\text{image}}}{\text{FWHM}_{\text{seeing}} / s}
\end{equation}

where $s$ is the pixel scale in arcsec/pixel and $\text{FWHM}_{\text{seeing}}$ is set by \texttt{--seeing-fwhm} (default: 3.0 arcsec).

Objects with $\text{CLASS\_STAR} \approx 1$ are point-like (stars), while $\text{CLASS\_STAR} \approx 0$ indicates extended sources (galaxies).

\begin{remark}[Classifier Limitations]
This is a simple heuristic classifier, not the neural-network-based classifier used by SExtractor. For accurate star/galaxy separation, use dedicated tools such as \texttt{PSFEx} + SExtractor or machine learning classifiers.
\end{remark}


\section{Flags}

The \texttt{FLAGS} column is a bitmask combining detection and photometry flags:

\begin{center}
\begin{tabular}{ccl}
\toprule
\textbf{Bit} & \textbf{Value} & \textbf{Meaning} \\
\midrule
0 & 1 & Object has neighbors (bright and close enough to bias photometry) \\
1 & 2 & Object was originally blended with another \\
2 & 4 & At least one pixel is saturated (peak $+$ background $\geq$ \texttt{SATURATE}) \\
3 & 8 & Object is truncated (too close to image boundary) \\
4 & 16 & Aperture data incomplete or corrupted \\
5 & 32 & Isophotal data incomplete or corrupted \\
\bottomrule
\end{tabular}
\end{center}

Multiple flags can be set simultaneously. For example, \texttt{FLAGS = 3} means the object has neighbors (1) and was deblended (2).

\section{WCS Coordinate Transformation}

If the FITS header contains valid World Coordinate System (WCS) keywords (\texttt{CRPIX}, \texttt{CRVAL}, \texttt{CD} or \texttt{CDELT}+\texttt{CROTA}), pixel coordinates are converted to celestial coordinates (J2000 equatorial):

\begin{codebox}[WCS transformation]
\begin{lstlisting}[style=python,numbers=none]
wcs = WCS(header)

\chapter{Intra-Cluster Light (ICL) Detection}
\label{ch:icl}
%======================================================

Intra-Cluster Light (ICL) is the diffuse stellar component in galaxy clusters, produced by tidal stripping of member galaxies during gravitational interactions.  ICL typically has surface brightness $\mu_V \gtrsim 26$\,mag/arcsec$^2$---far below the night sky background---requiring specialized techniques that preserve the faint extended signal \parencite{montes2018,rudick2011}.

The \textbf{ICL} menu provides a complete step-by-step pipeline for detecting, modeling, and measuring ICL from deep imaging data.  The pipeline draws on established methods: surface brightness threshold decomposition \parencite{rudick2011,jimenez-teja2018}, double S\'ersic BCG+ICL profile fitting \parencite{kluge2020}, and multi-band color gradient analysis \parencite{montes2018,huang2018}.

\section{Pipeline Overview}

The ICL detection pipeline follows a multi-step workflow, each accessible from the ICL menu:

\begin{enumerate}[leftmargin=2em]
  \item \textbf{Source Masking} --- Detect compact sources, expand the segmentation map to cover PSF wings, mask bright stars with magnitude-dependent radii, and interpolate masked regions.  The masked image is automatically displayed in a new frame.
  \item \textbf{Background Modeling} --- Fit a large-scale background model (polynomial, Chebyshev, or SEP large-mesh), optionally with iterative refinement and convergence monitoring.  The background-subtracted image is automatically displayed in a new frame.
  \item \textbf{Surface Brightness Profile} --- Measure the azimuthally averaged (or sector-based) SB profile centered on the BCG.  Annulus ring markers are drawn at 25\%, 50\%, 75\%, and 100\% of $r_\mathrm{max}$.
  \item \textbf{ICL Measurements} --- Compute $f_\mathrm{ICL}$, isophotal radii at specified SB levels, and integrated luminosity.  Isophotal radius circles are drawn as magenta dashed markers.
  \item \textbf{Multi-Threshold ICL} --- Sweep $\mu_\mathrm{threshold}$ over a range and compute $f_\mathrm{ICL}$ with bootstrap uncertainty at each level.
  \item \textbf{BCG+ICL Decomposition} --- Fit a double S\'ersic profile to separate BCG and ICL components, yielding $n_\mathrm{BCG}$, $n_\mathrm{ICL}$, $R_\mathrm{transition}$, and a profile-based $f_\mathrm{ICL}$.
\end{enumerate}

Additional tools: Color Profile (multi-band SB + color gradients), Save/Load Profile, and a comprehensive Settings dialog.

\section{Source Masking}
\label{sec:icl-mask}

\textbf{Menu}: ICL $\to$ 1.\ Source Masking

Compact sources (stars and galaxies) must be aggressively masked before ICL analysis, because their extended PSF wings contaminate the faint diffuse signal.

The masking procedure:
\begin{enumerate}[leftmargin=2em]
  \item Run SEP detection on the image at a configurable threshold (default: $1.5\sigma$) to produce a segmentation map.
  \item Expand each segment by a factor of \texttt{expand-factor} (default: 2.5) times its equivalent circular radius, capped at \texttt{max-dilate-radius} (default: 50\,px) to prevent over-masking in crowded fields:
  \begin{equation}
    r_\mathrm{dilate} = \min\!\bigl(f_\mathrm{expand} \times \sqrt{N_\mathrm{pix}/\pi},\; r_\mathrm{max}\bigr)
  \end{equation}
  Segments are grouped by dilation radius and batch-dilated; for $r > 30$\,px, \texttt{distance\_transform\_edt} is used (O($N$) regardless of radius) instead of \texttt{binary\_dilation}.
  \item Add circular masks for bright stars (MAG\_AUTO $<$ \texttt{bright-star-mag-limit}) with magnitude-dependent radii:
  \begin{equation}
    r_\mathrm{star} = f_\mathrm{scale} \times 10^{-0.2(m - m_\mathrm{limit})}
  \end{equation}
  \item Interpolate masked pixels using surrounding unmasked pixels (\texttt{scipy.interpolate.griddata}, method: linear/cubic/nearest).  For large images, block-based processing with 2048-pixel blocks and 64-pixel overlap is used.
\end{enumerate}

\textbf{Outputs}: \texttt{\textasciitilde/.ds9/icl\_mask.fits} (binary mask), \texttt{\textasciitilde/.ds9/icl\_masked.fits} (interpolated image).

\textbf{Package}: \texttt{icl/masking.py} --- functions: \texttt{create\_source\_mask()}, \texttt{mask\_bright\_stars()}, \texttt{interpolate\_masked()}, \texttt{reproject\_mask()}.

\subsection{Save Mask As / Import Mask}
\label{sec:icl-mask-io}

\textbf{Menu}: ICL $\to$ Save Mask As\ldots{} / Import Mask\ldots

These two features allow reusing a mask created on one band (e.g., F814W) for another band (e.g., F606W) that may differ in image size or pixel scale.

\begin{itemize}[leftmargin=2em]
  \item \textbf{Save Mask As\ldots} --- Copies the current mask FITS (\texttt{\textasciitilde/.ds9/icl\_mask.fits}) to a user-selected path.  The saved mask retains WCS header keywords, enabling cross-band reprojection.
  \item \textbf{Import Mask\ldots} --- Loads an external mask FITS and reprojects it onto the current image via WCS coordinate matching.  The reprojected mask and interpolated masked image are saved to the standard locations and automatically displayed in a new frame.
\end{itemize}

\noindent\textbf{WCS Reprojection Algorithm} (\texttt{reproject\_mask()} in \texttt{icl/masking.py}):

\begin{enumerate}[leftmargin=2em]
  \item \textbf{Header comparison}: Compare NAXIS1/2, CRPIX1/2, CRVAL1/2, and CD matrix between mask and target.
  \item \textbf{Case~A --- Direct copy}: If shape and WCS match (or no WCS and same shape), return the mask unchanged.
  \item \textbf{Case~B --- WCS transform}: Build the full target pixel grid, convert to sky coordinates via \texttt{WCS.pixel\_to\_world()}, then back to mask pixel coordinates via \texttt{WCS.world\_to\_pixel()}.  Nearest-neighbor rounding is used (the only correct interpolation for boolean masks).  Out-of-bounds pixels are set to unmasked.
\end{enumerate}

\noindent The algorithm is fully vectorized with NumPy and handles $>30$\,M pixels in a few seconds.  It is shared between the ICL and LSBG pipelines (\texttt{from icl.masking import reproject\_mask}).

\section{Background Modeling}
\label{sec:icl-bkg}

\textbf{Menu}: ICL $\to$ 2.\ Background Model $\to$ Polynomial Fit / Chebyshev Fit / SEP Large Mesh

Standard SExtractor-style backgrounds (mesh size $\sim$64\,px) subtract the ICL signal as part of the ``sky.''  The ICL pipeline uses methods with much larger scales to preserve diffuse emission.

\begin{center}
\begin{longtable}{L{3.5cm} L{9.0cm}}
\toprule
\textbf{Method} & \textbf{Description} \\
\midrule
\endhead

\midrule

\subsection{Iterative Background Refinement}

When the ``Iterative refinement'' option is enabled in the Settings dialog (Background tab), the pipeline performs iterative background fitting with convergence monitoring---the same approach used in the LSBG pipeline (Section~\ref{sec:lsbg-bkg}).

\begin{enumerate}[leftmargin=2em]
  \item Interpolate masked regions in the current mask (using the configured interpolation method).
  \item Fit background using the selected method.
  \item Compute residuals; detect residual sources at \texttt{bkg-refine-thresh}\,$\sigma$ (default: 2.0).
  \item Expand the mask to include newly detected sources.
  \item Check RMS convergence: if the fractional change in median $|\mathrm{residual}|$ is less than \texttt{bkg-convergence-tol} (default: 0.01), stop early.
  \item Repeat for up to \texttt{bkg-n-iterations} (default: 3) cycles.
\end{enumerate}

This is particularly useful for cluster fields where imperfect initial masking leaves residual source flux that biases the background estimate.

\textbf{Outputs}: \texttt{\textasciitilde/.ds9/icl\_background.fits} (background model), \texttt{\textasciitilde/.ds9/icl\_bgsub.fits} (background-subtracted image).

\textbf{Package}: \texttt{icl/background.py} --- functions: \texttt{fit\_polynomial\_background()}, \texttt{fit\_chebyshev\_background()}, \texttt{sep\_large\_mesh\_background()}, \texttt{iterative\_background\_icl()}.


\section{Surface Brightness Profile}
\label{sec:icl-profile}

\textbf{Menu}: ICL $\to$ 3.\ Set BCG Center / Measure Profile / Sector Profile\ldots

The SB profile is measured in concentric elliptical annuli centered on the BCG (brightest cluster galaxy).

\subsection{BCG Center Selection}

Selecting ``Set BCG Center'' opens a dialog with three options:

\begin{enumerate}[leftmargin=2em]
  \item \textbf{Source ID entry} (default) --- Enter the source \texttt{NUMBER} from the SExtractor catalog.  The dialog searches the \emph{first frame}'s catalog (i.e., the original image extraction) so that the BCG is available even when the current frame shows a masked or background-subtracted image where the BCG has been removed.  The brightest source (lowest \texttt{MAG\_AUTO}) is suggested as the default.
  \item \textbf{Click on Image} --- Click the ``Click on Image'' button in the dialog, then click directly on the image to set the BCG position.  A cyan cross marker is drawn at the selected location.
  \item \textbf{CLI} --- Use the \texttt{--center x,y} argument (0-indexed pixel coordinates).
\end{enumerate}

\subsection{Profile Measurement}

For each annular bin between $r_\mathrm{min}$ and $r_\mathrm{max}$ (default: 5--1000\,px), the pipeline:
\begin{enumerate}[leftmargin=2em]
  \item Creates an elliptical annulus mask with the specified ellipticity and position angle.
  \item Computes $3\sigma$-clipped mean flux and standard error of unmasked pixels.
  \item Converts to surface brightness:
  \begin{equation}
    \mu(r) = \mathrm{ZP} - 2.5\log_{10}\!\Bigl(\frac{\bar{f}}{s^2}\Bigr)
  \end{equation}
  where $\bar{f}$ is the mean flux per pixel, $s$ is the pixel scale (arcsec/px), and ZP is the magnitude zeropoint.
\end{enumerate}

Radial bins can use logarithmic spacing (default) or linear spacing.  Sector profiles restrict the annulus to a specified azimuthal wedge (PA, width).

\section{ICL Fraction Measurement}
\label{sec:icl-measure}

\textbf{Menu}: ICL $\to$ 4.\ ICL Measurements

Computes integrated ICL quantities from the SB profile:

\begin{itemize}[leftmargin=2em]
  \item \textbf{ICL fraction}: $f_\mathrm{ICL} = L_\mathrm{ICL} / (L_\mathrm{ICL} + L_\mathrm{gal})$, where $L_\mathrm{ICL}$ is the luminosity at $\mu > \mu_\mathrm{threshold}$ (default: 26.5\,mag/arcsec$^2$).
  \item \textbf{Isophotal radii}: Radii where the SB profile crosses specified isophotes (default: $\mu = 26.0, 27.0, 28.0$\,mag/arcsec$^2$).
  \item \textbf{Integrated luminosities}: $L_\mathrm{ICL}$ and $L_\mathrm{gal}$ computed by integrating the SB profile over annular areas.
\end{itemize}

\textbf{Package}: \texttt{icl/measure.py} --- functions: \texttt{compute\_icl\_fraction()}, \texttt{compute\_isophotal\_radii()}, \texttt{summarize\_icl()}.


\section{Multi-Threshold ICL Fraction}
\label{sec:icl-multi}

\textbf{Menu}: ICL $\to$ Multi-Threshold ICL

Instead of computing $f_\mathrm{ICL}$ at a single threshold, this mode sweeps over a range of SB thresholds and reports the ICL fraction at each level, with bootstrap uncertainty estimates:

\begin{enumerate}[leftmargin=2em]
  \item Generate threshold array: $\mu_\mathrm{min}$ to $\mu_\mathrm{max}$ with step $\Delta\mu$ (defaults: 25.0 to 28.0, step 0.5\,mag/arcsec$^2$).
  \item At each threshold $\mu_t$, compute $f_\mathrm{ICL}(\mu_t)$ from the SB profile.
  \item Bootstrap error: resample the profile 200 times (with replacement) and compute $\sigma(f_\mathrm{ICL})$.
\end{enumerate}

\section{BCG+ICL Decomposition}
\label{sec:icl-decompose}

\textbf{Menu}: ICL $\to$ 5.\ BCG+ICL Decomposition

An alternative to the SB threshold method is to decompose the radial profile into two S\'ersic components: a concentrated BCG and an extended ICL envelope \parencite{kluge2020,montes2018}.  The model is:
\begin{equation}
  I(r) = I_\mathrm{e,BCG}\,\exp\!\biggl[-b_{n_1}\Bigl(\bigl(\frac{r}{r_\mathrm{e,BCG}}\bigr)^{1/n_1} - 1\Bigr)\biggr]
       + I_\mathrm{e,ICL}\,\exp\!\biggl[-b_{n_2}\Bigl(\bigl(\frac{r}{r_\mathrm{e,ICL}}\bigr)^{1/n_2} - 1\Bigr)\biggr]
\end{equation}
where $b_n \approx 1.9992n - 0.3271$.

\subsection{Fitting Algorithm}

\begin{enumerate}[leftmargin=2em]
  \item Convert $\mu(r)$ (mag/arcsec$^2$) to linear intensity $I(r)$.
  \item Fit a single 1D S\'ersic (using \texttt{lsbg.sersic.fit\_sersic\_1d()}) for initial parameter estimates.
  \item Initialize: BCG ($I_e \times 1.5$, $r_e \times 0.5$, $n \geq 2$) and ICL ($I_e \times 0.3$, $r_e \times 3$, $n \geq 0.5$).
  \item Fit the double S\'ersic via \texttt{scipy.optimize.curve\_fit} with bounds: $n_\mathrm{BCG} \in [1, 10]$, $n_\mathrm{ICL} \in [0.2, 6]$.
  \item Post-fit: if $r_\mathrm{e,ICL} < r_\mathrm{e,BCG}$, swap components.
  \item Compute the transition radius $R_\mathrm{transition}$ where the two components are equal (using \texttt{scipy.optimize.brentq}).
  \item Integrate each component analytically for the profile-based ICL fraction: $f_\mathrm{ICL,S\'ersic} = F_\mathrm{ICL} / (F_\mathrm{BCG} + F_\mathrm{ICL})$.
\end{enumerate}

\subsection{Output}

\begin{center}
\begin{tabular}{ll}
\toprule
\textbf{Key} & \textbf{Description} \\
\midrule
\texttt{n\_bcg}, \texttt{n\_icl} & S\'ersic indices \\
\texttt{re\_bcg}, \texttt{re\_icl} & Effective radii (px and arcsec) \\
\texttt{R\_transition} & Radius where BCG = ICL (px and arcsec) \\
\texttt{f\_ICL\_sersic} & ICL fraction from integrated S\'ersic fluxes \\
\texttt{chi2} & Reduced $\chi^2$ of the fit \\
\bottomrule
\end{tabular}
\end{center}

\textbf{Package}: \texttt{icl/decompose.py} --- functions: \texttt{double\_sersic\_1d()}, \texttt{fit\_double\_sersic()}.

\textbf{Menu}: ICL $\to$ Color Profile\ldots

\section{Export / Import Script}
\label{sec:icl-export-import}

\textbf{Menu}: ICL $\to$ Export Script\ldots{} / Import Script\ldots

The \textbf{Export Script} feature saves the ICL pipeline commands executed in the current GUI session as a standalone bash script.  Two modes are supported:

\begin{enumerate}
  \item \textbf{Command log mode} --- If any ICL commands have been executed (Mask, Background, Profile, etc.), the exact commands are exported in execution order.
  \item \textbf{Settings-based fallback} --- If no commands have been executed, a full 4-step pipeline script (mask $\to$ background $\to$ profile $\to$ measure) is generated from the current parameter settings.
\end{enumerate}

\noindent The exported script substitutes file paths with shell variables for portability:

\begin{itemize}
  \item \texttt{\$INPUT} --- The input FITS file (first positional argument)
  \item \texttt{\$OUTDIR} --- Output directory for intermediate files (second argument, default \texttt{./output})
  \item \texttt{\$SCRIPT\_DIR} --- Directory containing \texttt{ds9\_icl.py}
\end{itemize}

\begin{codebox}[Usage]
\begin{lstlisting}[style=bash,numbers=none]
bash icl_pipeline.sh input.fits ./output
\end{lstlisting}
\end{codebox}

\noindent The \textbf{Import Script} feature loads a previously exported \texttt{.sh} file and re-executes all \texttt{python3} commands against the currently loaded FITS image.  Variable substitution is applied in reverse (\texttt{\$INPUT} $\to$ current FITS path, \texttt{\$OUTDIR} $\to$ \texttt{\textasciitilde/.ds9/}).  After execution, the best available result image (background-subtracted or masked) is displayed in a new frame, and any TSV output is loaded into the catalog table.

\begin{important}
The command log is reset each time a new Mask operation is started, so the exported script reflects the most recent analysis session.
\end{important}

%======================================================
\chapter{Low Surface Brightness Galaxy (LSBG) Detection}
\label{ch:lsbg}
%======================================================

Low Surface Brightness Galaxies (LSBGs) have effective surface brightness $\mu_\mathrm{eff} > 24$\,mag/arcsec$^2$, making them extremely difficult to detect with standard source extraction.  The key challenges are:
\begin{enumerate}[leftmargin=2em]
  \item \textbf{Bright-source contamination}: PSF wings and halos from bright objects overlap LSBG signal.
  \item \textbf{Background over-subtraction}: Standard background estimation (small mesh sizes) treats the LSBG itself as background and subtracts it.
  \item \textbf{Low SNR}: LSBGs have total SNR of only $2\text{--}5\sigma$, requiring aggressive filtering to separate real detections from noise.
\end{enumerate}

The \textbf{LSBG} menu implements a literature-based approach inspired by SMUDGes \parencite{zaritsky2019}, NoiseChisel \parencite{akhlaghi2015}, and DeepScan \parencite{prole2018}:

\begin{equation*}
\text{Mask} \;\longrightarrow\; \text{Iterative Background} \;\longrightarrow\; \text{Low-}\sigma\text{ Detection} \;\longrightarrow\; \text{Photometry \& Filter}
\end{equation*}

\section{Pipeline Overview}

\begin{center}
\begin{longtable}{C{0.5cm} L{3.5cm} L{8.5cm}}
\toprule
\textbf{\#} & \textbf{Step} & \textbf{Description} \\
\midrule
\endhead
1 & Mask Bright Sources & Selectively mask only bright sources ($m < m_\mathrm{thresh}$), preserving faint LSBG candidates.  Interpolate masked regions. \\
\midrule
2 & Iterative Background & Repeat: fit background $\to$ detect residuals $\to$ expand mask $\to$ re-fit (2--3 iterations). \\
\midrule
3 & Detect LSBG Candidates & Low-threshold ($0.8\sigma$) detection with large convolution kernels on the cleaned image. \\
\midrule
4 & Photometry + Filter & Kron/aperture photometry, curve-of-growth $R_\mathrm{eff}$, $\mu_\mathrm{eff}$, then select by surface brightness, size, shape, and SNR. \\
\bottomrule
\end{longtable}
\end{center}

All steps can be run individually from the LSBG menu, or as a single pipeline via ``Run Full Pipeline.''


\section{Step 1: Magnitude-Based Selective Masking}
\label{sec:lsbg-mask}

\textbf{Menu}: LSBG $\to$ 1.\ Mask Bright Sources

Unlike the ICL masking that masks \emph{all} detected sources, LSBG masking selectively masks only sources brighter than a magnitude threshold (\texttt{mask-mag-threshold}, default: 22.0\,mag), preserving faint LSBG candidates.

\begin{enumerate}[leftmargin=2em]
  \item Run SEP detection at \texttt{mask-detect-thresh}$\,\sigma$ (default: 1.5) to produce a segmentation map.
  \item For each segment, compute a calibrated magnitude from SEP flux using the photometric zeropoint: $m = m_\mathrm{ZP} - 2.5\log_{10}(f)$.  Only segments with $m < m_\mathrm{thresh}$ are selected for masking.
  \item \textbf{LSB structure protection} \parencite{greco2018}: When enabled (\texttt{lsb-protect}), compute the mean surface brightness of each segment.  Sources with $\mu_\mathrm{mean} \geq \mu_\mathrm{LSB}$ (default: 24.0\,mag/arcsec$^2$) are skipped to preserve potential LSBGs that would otherwise be masked.
  \item Dilate selected segments by \texttt{mask-expand-factor} (default: 1.5) times their equivalent circular radius, capped at \texttt{max-dilate-radius} (default: 30\,px) to prevent over-masking of extended sources.  The expansion factor follows \textcite{prole2018}, who use a factor of~1.5 for bright galaxies.
  \item Add bright star masks (same algorithm as ICL: magnitude-dependent circular masks).
  \item Interpolate all masked regions using iterative Gaussian-weighted fill (parallelized via \texttt{ThreadPoolExecutor}).
\end{enumerate}

\subsection{Masking Parameter Comparison with Literature}

\begin{center}
\begin{tabular}{L{3.5cm} L{2cm} L{2cm} L{5cm}}
\toprule
\textbf{Parameter} & \textbf{Our value} & \textbf{Literature} & \textbf{Reference} \\
\midrule
Expand factor          & 1.5  & 1.5            & \textcite{prole2018}: aperture enlargement for bright galaxies \\
Max dilate radius      & 30\,px & 5--30\,FWHM  & \textcite{zaritsky2019}: Moffat fit range limit \\
Detection $\sigma$     & 1.5  & 0.5--6         & \textcite{prole2018}: 6$\sigma$ for mask creation; \textcite{infante-sainz2020}: 0.5$\sigma$ \\
Magnitude threshold    & 22.0 & ---            & Most pipelines mask all detected sources \\
RMS quantile           & 0.25 & 0.159          & \textcite{prole2018}: 15.9\% (1$\sigma$ below median) \\
\bottomrule
\end{tabular}
\end{center}

\noindent Alternative masking approaches in the literature include dual-threshold replacement \parencite{greco2018,carlsten2020}, isophotal masking to $\mu = 29\text{--}30$\,mag/arcsec$^2$ \parencite{prole2018,infante-sainz2020}, and model subtraction (MRF; \textcite{vandokkum2020}).

The masking reuses functions from the ICL pipeline (\texttt{icl.masking}):
\begin{itemize}[leftmargin=2em]
  \item \texttt{mask\_by\_magnitude()} --- magnitude-selective segment dilation (parallelized via \texttt{SharedArray})
  \item \texttt{mask\_bright\_stars()} --- bright star circular masks
  \item \texttt{interpolate\_masked()} --- Gaussian-weighted iterative fill
\end{itemize}

\textbf{Outputs}: \texttt{\textasciitilde/.ds9/lsbg\_mask.fits} (binary mask), \texttt{\textasciitilde/.ds9/lsbg\_masked.fits} (interpolated image).

\textbf{Package}: \texttt{lsbg/masking.py} --- functions: \texttt{mask\_by\_magnitude()}, \texttt{iterative\_mask\_refine()}, \texttt{create\_lsbg\_mask()}.

\subsection{Save Mask As / Import Mask}
\label{sec:lsbg-mask-io}

\textbf{Menu}: LSBG $\to$ Save Mask As\ldots{} / Import Mask\ldots

Same functionality as the ICL mask I/O (Section~\ref{sec:icl-mask-io}): save the current LSBG mask to a user-selected path, or import an external mask FITS with automatic WCS reprojection.  This is useful for applying a mask created on a deep detection band to shallower bands for forced photometry.  The reprojection uses the shared \texttt{reproject\_mask()} function from \texttt{icl.masking}.


\section{Step 2: Iterative Background Refinement}
\label{sec:lsbg-bkg}

\textbf{Menu}: LSBG $\to$ 2.\ Background Model $\to$ SEP Large Mesh / Polynomial / Chebyshev

Standard single-pass background estimation fails for LSBG detection because:
\begin{itemize}[leftmargin=2em]
  \item Small mesh sizes subtract the diffuse LSBG signal.
  \item Residual source flux (from imperfect masking) biases the background upward.
\end{itemize}

The iterative algorithm repeats for \texttt{bkg-n-iterations} (default: 3) cycles:
\begin{enumerate}[leftmargin=2em]
  \item Interpolate masked regions in the current mask.
  \item Fit background using the selected method (SEP large mesh / polynomial / Chebyshev), reusing functions from \texttt{icl.background}.
  \item Detect residual sources in the background-subtracted residual at \texttt{bkg-refine-thresh}$\,\sigma$ (default: 2.0).
  \item Expand the mask to include newly detected residuals.
  \item \textbf{RMS convergence check}: Compute the median $|\mathrm{residual}|$ in unmasked regions.  If the fractional change is less than \texttt{bkg-convergence-tol} (default: 0.01), stop early.
  \item If no new sources are found, also declare convergence and stop early.
\end{enumerate}

\subsection{Lower-Quantile RMS}

Standard RMS estimates include noise from bright-source residuals, reducing sensitivity to faint diffuse emission.  The \texttt{compute\_quantile\_rms()} function computes the RMS from the lower quantile of local noise values (\texttt{bkg-rms-quantile}, default: 0.25), giving a noise estimate representative of the quietest regions and making faint LSBG sources $1.5\text{--}2\times$ more detectable.

\subsection{Parallel Tiled Background Fitting}

For large images, the background fitting is parallelized:
\begin{itemize}[leftmargin=2em]
  \item The image is split into 1024-pixel tiles with 128-pixel overlap.
  \item Each tile is fitted independently using \texttt{parallel\_map()} from the \texttt{parallel/} package.
  \item Tiles are blended using 2D cosine weighting to eliminate boundary artifacts:
  \begin{equation}
    w(x) = \frac{1}{2}\bigl(1 - \cos(\pi x / L_\mathrm{overlap})\bigr)
  \end{equation}
  \item Image data and mask are shared across workers via \texttt{SharedArray} (zero-copy).
\end{itemize}

\textbf{Outputs}: \texttt{\textasciitilde/.ds9/lsbg\_background.fits} (final background), \texttt{\textasciitilde/.ds9/lsbg\_cleaned.fits} (background-subtracted).

\textbf{Package}: \texttt{lsbg/background.py} --- functions: \texttt{fit\_background\_parallel()}, \texttt{iterative\_background()}.


\section{Step 3: Low-Threshold Detection}
\label{sec:lsbg-detect}

\textbf{Menu}: LSBG $\to$ 3.\ Detect LSBG Candidates

After background subtraction, candidate LSBG sources are detected with aggressive low-threshold settings designed to catch faint diffuse objects:

\begin{center}
\begin{tabular}{lll}
\toprule
\textbf{Parameter} & \textbf{Default} & \textbf{Purpose} \\
\midrule
\texttt{detect-thresh} & 0.8$\sigma$ & Very low threshold (cf.\ standard 1.5$\sigma$) \\
\texttt{detect-minarea} & 50\,px & Large minimum area filters point-like noise \\
\texttt{detect-filter-kernel} & gauss5x5 & Convolution kernel enhances diffuse signal \\
\texttt{deblend-nthresh} & 32 & Deblending sub-thresholds \\
\texttt{deblend-mincont} & 0.005 & Minimum contrast for deblending \\
\bottomrule
\end{tabular}
\end{center}

\subsection{Convolution Kernels}

Larger kernels preferentially enhance extended emission while suppressing point-source noise:

\begin{center}
\begin{tabular}{ll}
\toprule
\textbf{Kernel} & \textbf{Description} \\
\midrule
\texttt{gauss3x3}--\texttt{gauss9x9} & Gaussian with FWHM 3--9\,px \\
\texttt{tophat5}, \texttt{tophat7} & Flat circular kernels (5 or 7\,px diameter) \\
\texttt{mexhat} & Mexican-hat wavelet ($\sigma=2$\,px) \\
\texttt{none} & No convolution \\
\bottomrule
\end{tabular}
\end{center}

\subsection{Multi-Scale Detection}

When enabled (\texttt{multiscale}=true, default), the pipeline detects sources at multiple spatial scales and merges the results:

\begin{enumerate}[leftmargin=2em]
  \item \textbf{Native scale (1$\times$)}: Standard detection at the original pixel resolution.
  \item \textbf{Rebinned scales (2$\times$, 4$\times$)}: The image is rebinned by block-averaging.  Detection is run with a slightly lower threshold ($0.9\times$) to account for reduced noise ($\sigma_\mathrm{rebin} = \sigma / \sqrt{N}$), and minimum area is scaled by $1/\mathrm{factor}^2$.
  \item \textbf{Merge}: Rebinned detections are mapped back to native coordinates.  Duplicates are removed by cross-matching within \texttt{match\_radius}~$\times$~scale.  Native-scale detections are prioritized.
\end{enumerate}

This multi-scale approach \parencite{greco2018,prole2018} recovers very extended low-SB galaxies that are diluted below the detection threshold at the native resolution, while preserving spatial accuracy for compact LSBGs.

\textbf{Outputs}: \texttt{\textasciitilde/.ds9/lsbg\_segmap.fits} (segmentation map), detection catalog displayed in the table.

\textbf{Package}: \texttt{lsbg/detection.py} --- functions: \texttt{build\_convolution\_kernel()}, \texttt{detect\_lsbg\_candidates()}, \texttt{detect\_multiscale()}.


\section{Step 4: Photometry and LSBG Filtering}
\label{sec:lsbg-phot}

\textbf{Menu}: LSBG $\to$ 4.\ Photometry + Filter

Each detected candidate undergoes detailed photometric measurement and then LSBG selection criteria are applied.

\subsection{Photometric Measurements}

For each source, the following are measured:

\begin{enumerate}[leftmargin=2em]
  \item \textbf{Kron photometry}: Kron radius via \texttt{sep.kron\_radius()}, then elliptical aperture flux at $2.5\times r_\mathrm{Kron}$.
  \item \textbf{Fixed circular apertures}: Flux in 5, 10, 20, 40-pixel radius circles via \texttt{sep.sum\_circle()}.
  \item \textbf{Curve of growth}: Cumulative flux measured in 25 logarithmically-spaced radii from 2 to $4\times\max(a,b)$\,px.  The half-light radius $R_\mathrm{eff}$ is interpolated as the radius enclosing 50\% of the total flux.
  \item \textbf{Effective surface brightness}:
  \begin{equation}
    \mu_\mathrm{eff} = \mathrm{ZP} - 2.5\log_{10}\!\Bigl(\frac{F_\mathrm{total}/2}{\pi\,R_\mathrm{eff}^2}\Bigr) \quad [\text{mag/arcsec}^2]
  \end{equation}
  where $R_\mathrm{eff}$ is in arcsec.
\end{enumerate}

Photometry is parallelized: image data and RMS map are shared via \texttt{SharedArray}, and individual sources are processed by \texttt{parallel\_map()}.

\subsection{LSBG Selection Criteria}

After photometry, sources are filtered by four criteria:

\begin{center}
\begin{tabular}{lll}
\toprule
\textbf{Criterion} & \textbf{Range} & \textbf{Default} \\
\midrule
$\mu_\mathrm{eff}$ (mag/arcsec$^2$) & $[\mu_\mathrm{min}, \mu_\mathrm{max}]$ & $[24.0, 30.0]$ \\
$R_\mathrm{eff}$ (arcsec) & $[R_\mathrm{min}, R_\mathrm{max}]$ & $[2.5, 60.0]$ \\
Ellipticity & $< \epsilon_\mathrm{max}$ & $< 0.7$ \\
SNR & $> \mathrm{SNR}_\mathrm{min}$ & $> 2.0$ \\
\bottomrule
\end{tabular}
\end{center}

\subsection{S\'ersic Profile Fitting}

When enabled (\texttt{sersic-fit}=true, default), each candidate undergoes 1D~$\to$~2D S\'ersic profile fitting \parencite{sersic1968,graham2005}:

\begin{enumerate}[leftmargin=2em]
  \item Extract a square cutout ($5\times$ Kron radius) around the source.
  \item Extract the azimuthally-averaged radial profile in elliptical annuli.
  \item Fit 1D S\'ersic $I(r) = I_e \exp[-b_n((r/r_e)^{1/n} - 1)]$ for initial guesses ($I_e, r_e, n$).
  \item Fit full 2D S\'ersic model (8 parameters: $I_e, r_e, n, x_c, y_c, \epsilon, \theta, \mathrm{bg}$) using \texttt{scipy.optimize.least\_squares} (TRF method).
  \item Compute reduced $\chi^2$, analytical total flux, and S\'ersic-based effective surface brightness.
\end{enumerate}

\subsection{S\'ersic-Based Filtering}

In addition to the photometric criteria, sources are filtered by S\'ersic fit quality:
\begin{itemize}[leftmargin=2em]
  \item Reject if $n < 0.3$ (likely artifact or noise).
  \item Reject if $n > 6.0$ (too concentrated for an LSBG).
  \item Reject if $\chi^2 > 10$ (poor S\'ersic fit quality).
\end{itemize}

\subsection{Confidence Score and Grading}

Each passing source receives an LSBG confidence score (0--1) computed as a weighted combination:

\begin{equation}
C = w_\mu\,S_\mu + w_R\,S_R + w_\epsilon\,S_\epsilon + w_\mathrm{SNR}\,S_\mathrm{SNR} + w_\mathrm{S\'ersic}\,S_\mathrm{S\'ersic}
\end{equation}

where $S_\mu$ peaks at the center of the $[\mu_\mathrm{min}, \mu_\mathrm{max}]$ range, $S_R$ favors larger sizes, $S_\epsilon$ favors rounder shapes, $S_\mathrm{SNR}$ scales with signal-to-noise, and $S_\mathrm{S\'ersic}$ (25\% weight when available) combines a S\'ersic $n$ score (favoring the typical LSBG range $0.5 \leq n \leq 2$) with a $\chi^2$ quality score.

The confidence score is mapped to a letter grade:
\begin{center}
\begin{tabular}{ccl}
\toprule
\textbf{Grade} & \textbf{Confidence} & \textbf{Interpretation} \\
\midrule
A & $\geq 0.7$ & High-confidence LSBG candidate \\
B & $\geq 0.5$ & Probable LSBG candidate \\
C & $\geq 0.3$ & Marginal candidate (needs visual inspection) \\
D & $< 0.3$ & Likely artifact or non-LSBG \\
\bottomrule
\end{tabular}
\end{center}

\textbf{Package}: \texttt{lsbg/photometry.py}, \texttt{lsbg/filtering.py}, \texttt{lsbg/sersic.py}.

\chapter{Planned Features and Science-Driven Extensions}
\label{ch:future}
%======================================================

This chapter outlines features motivated by upcoming survey science requirements, particularly the Vera C.\ Rubin Observatory Legacy Survey of Space and Time (LSST).

\section{LSST / Large-Scale Survey Features}

The LSST will produce $\sim$20\,TB of imaging data per night across six filters ($ugrizy$), resulting in $\sim$60\,PB over its 10-year survey. Processing and inspecting such data volumes requires features beyond single-image analysis.

\subsection{Batch Processing Pipeline}

Process multiple FITS files in sequence or parallel from the command line, with per-file output catalogs:

\begin{codebox}[Batch mode]
\begin{lstlisting}[style=bash,numbers=none]
# Process all FITS files with 8 parallel workers
python3 ds9_morphometry.py --batch field*.fits \
    --catalog cat.tsv --n-workers 8 --output-dir results/

# Future MPI extension (no code changes needed):
mpirun -np 16 python3 ds9_morphometry.py --batch *.fits \
    --output-dir results/
\end{lstlisting}
\end{codebox}

\textbf{Status}: Implemented. All CLI scripts support \texttt{--n-workers} and \texttt{--batch} arguments via the \texttt{parallel/} package.

\subsection{Multi-Extension FITS (MEF) Support}

LSST CCDs produce Multi-Extension FITS files with one extension per amplifier or detector. Features needed:
\begin{itemize}[leftmargin=2em]
  \item Auto-detect and iterate over all image extensions
  \item Per-extension background subtraction and source extraction
  \item Unified catalog with extension ID column
  \item Mosaic assembly for visualization
\end{itemize}

\subsection{Tile/Tract-Based Catalog Management}

LSST data products are organized as sky tiles (tracts/patches). Features needed:
\begin{itemize}[leftmargin=2em]
  \item Load catalogs from Butler data repositories or Parquet files
  \item Spatial indexing (HEALPix, HTM) for efficient viewport queries
  \item Cross-tract deduplication within overlap regions
  \item Catalog streaming --- load only sources within the current viewport for catalogs with $>10^6$ sources
\end{itemize}

\subsection{Difference Imaging Transient Detection}

LSST alert production relies on image differencing. Features needed:
\begin{itemize}[leftmargin=2em]
  \item \textbf{Template subtraction}: Subtract a template (coadd) image from a visit image using kernel matching (e.g., Alard \& Lupton 1998, ZOGY)
  \item \textbf{Dipole detection}: Detect positive/negative dipole pairs from astrometric misalignment or moving objects
  \item \textbf{Transient classification}: Real/bogus classification of difference-image detections using a pre-trained CNN
  \item \textbf{Light curve viewer}: Plot photometric history of a selected transient across epochs
\end{itemize}

\subsection{Forced Photometry}

Measure flux at fixed positions across multiple epochs or bands, even when the source is below the detection threshold:
\begin{itemize}[leftmargin=2em]
  \item Input: reference catalog positions + per-epoch FITS images
  \item Output: per-epoch flux measurements with uncertainties
  \item Essential for faint variable sources and upper limit estimation
\end{itemize}

\subsection{Quality Assurance Dashboard}

For survey-scale data, visualize data quality across fields:
\begin{itemize}[leftmargin=2em]
  \item Seeing FWHM, sky background, and zero-point maps across the focal plane
  \item Source count density and completeness maps
  \item Photometric residual plots (catalog $-$ reference)
  \item Astrometric residual quiver plots
\end{itemize}


\section{Additional Feature Ideas}

\textit{Note}: The Intra-Cluster Light (ICL) Detection and Low Surface Brightness Galaxy (LSBG) Detection pipelines described in the planned features of earlier versions are now fully implemented---see Chapters~\ref{ch:icl} and \ref{ch:lsbg}.
\bigskip

\subsection{Photometric Redshift Estimation}

Estimate photometric redshifts from multi-band photometry using template fitting or machine learning:
\begin{itemize}[leftmargin=2em]
  \item Template fitting: fit SED templates (e.g., from LePhare or EAZY) to multi-band magnitudes
  \item ML approach: train a neural network on spectroscopic redshift calibration samples
  \item Output columns: \texttt{ZPHOT\_BEST}, \texttt{ZPHOT\_ERR}, \texttt{ZPHOT\_PDF} (probability distribution)
  \item Critical for LSST cosmology: weak lensing, BAO, cluster mass calibration
\end{itemize}

\subsection{Weak Lensing Shape Measurement}

Measure galaxy shapes for weak gravitational lensing analysis:
\begin{itemize}[leftmargin=2em]
  \item PSF deconvolution of galaxy shapes using the built-in PSF model
  \item Ellipticity components $(e_1, e_2)$ and shear responsivity
  \item Model fitting: Gaussian or S\'ersic convolved with PSF
  \item PSF interpolation across the field of view
  \item Essential for LSST dark energy science
\end{itemize}

\subsection{Spectral Energy Distribution (SED) Viewer}

Interactive SED plotting from multi-band photometry:
\begin{itemize}[leftmargin=2em]
  \item Click a source to display its SED (flux vs.\ wavelength) in a popup window
  \item Overlay best-fit template from photometric redshift fitting
  \item Color-coded data points per filter
  \item Integrated with Multi-Band Photometry results
\end{itemize}

\subsection{Catalog Annotation and Flagging}

Manual annotation tools for visual inspection workflows:
\begin{itemize}[leftmargin=2em]
  \item Add custom text notes to individual sources
  \item Flag sources as ``artifact'', ``interesting'', ``needs review''
  \item Export flagged source lists for follow-up observation planning
  \item Useful for citizen science and expert review of LSST alerts
\end{itemize}

\subsection{Cluster Finder}

Automated galaxy cluster detection algorithms:
\begin{itemize}[leftmargin=2em]
  \item Red-sequence cluster finder (RedMaPPer-style) using multi-band colors
  \item Friends-of-friends clustering in projected space
  \item Voronoi tessellation density mapping
  \item Richness estimation and membership probability
\end{itemize}

\subsection{Parallel Processing}

Multi-core parallelization using \texttt{multiprocessing.shared\_memory} for CPU-intensive analyses:
\begin{itemize}[leftmargin=2em]
  \item Source-level parallelism for morphometry, S\'ersic fitting, PSF photometry
  \item Group-level parallelism for crowded field photometry
  \item Band-level parallelism for multi-band photometry
  \item Tile-level parallelism for LSBG background fitting
  \item Shared memory arrays avoid data copying overhead
  \item \texttt{--n-workers} CLI argument: 0=auto (cpu$-$1), 1=sequential, N=fixed
\end{itemize}

\textbf{Status}: Implemented in the \texttt{parallel/} package (\texttt{SharedArray}, \texttt{parallel\_map}). Used by morphometry, S\'ersic, PSF photometry, crowded field, multi-band, completeness, and LSBG pipelines.

\chapter{Worked Example: ICL Analysis of SMACS~J0723}
\label{ch:example}
%======================================================

This chapter demonstrates the complete ICL (Intra-Cluster Light) analysis
pipeline using JWST data of the galaxy cluster SMACS~J0723.3$-$7327
($z=0.39$), reproducing the analysis of
\textcite{montes2022}.\footnote{Montes \& Trujillo 2022, ApJ 940, L51 ---
``A New Era of Intracluster Light Studies with JWST''}
We show both the \textbf{command-line} workflow (a self-contained bash script)
and the equivalent \textbf{GUI} workflow using the DS9 ICL panel.

\section{Data and Goals}

\begin{itemize}
  \item \textbf{Cluster}: SMACS~J0723.3$-$7327, $z=0.39$,
        $M_h = 8.39\times10^{14}\,M_\odot$
  \item \textbf{Instrument}: JWST NIRCam LW, Module~B
        (pixel scale $0\rlap{.}{''}063$/pixel)
  \item \textbf{Filter}: F277W (exposure 7537\,s; JWST ERO Program 2736)
  \item \textbf{Data file}: \texttt{jwst\_smacs0723\_nircam\_f444w\_cutout.fits}
        (2040$\times$2040 pixels, 115\,MB)
  \item \textbf{Angular scale}: $5.277$\,kpc/arcsec at $z=0.39$
        (flat $\Lambda$CDM, $H_0=70$)
\end{itemize}

\noindent
The goals are to:
\begin{enumerate}
  \item Mask foreground sources while preserving diffuse ICL signal
  \item Subtract the large-scale background
  \item Measure the azimuthally-averaged surface brightness profile
        out to ${\sim}400$\,kpc (${\sim}72''$)
  \item Compute the ICL fraction at multiple SB thresholds
  \item Decompose the light into BCG and ICL components
        (double S\'ersic fit)
  \item Compare with the stellar mass density slope
        $\alpha_\mathrm{3D} = -2.47 \pm 0.13$ reported in \textcite{montes2022}
\end{enumerate}


\section{CLI Pipeline}
\label{sec:example-cli}

The complete analysis is encapsulated in
\texttt{scripts/reproduce\_montes2022.sh}.
Below we walk through each step with the exact commands.

\subsection{Configuration}

\begin{codebox}[Step 0: Parameters]
\begin{lstlisting}[style=bash,numbers=none]
PIXEL_SCALE=0.063     # arcsec/pixel (NIRCam LW)
MAG_ZP=auto           # auto-compute from FITS header (PIXAR_SR)
EXPAND_FACTOR=1.5     # source mask dilation factor
MAX_DILATE=20         # max dilation radius (pixels)
DETECT_THRESH=5.0     # detect only bright compact sources
BRIGHT_MAG=18.0       # bright-star masking limit
NSTEPS=51             # 51 logarithmic radial bins (as in the paper)
RMIN=3.0              # inner cutoff (~0.19")
RMAX=1143             # outer cutoff (~72" = 380 kpc)
CENTER="1004,1067"    # BCG center (smoothed-peak detection)
\end{lstlisting}
\end{codebox}

\begin{remark}
The zero-point is set to \texttt{auto}, which reads the \texttt{PIXAR\_SR}
keyword from the FITS header and computes
$\mathrm{ZP_{AB}} = -6.10 - 2.5\log_{10}(\texttt{PIXAR\_SR})$.
For this dataset, $\mathrm{ZP_{AB}} \approx 26.48$.
\end{remark}

\subsection{Step 1: Source Masking}

SEP-based source detection with controlled dilation to mask compact sources
while preserving diffuse ICL emission.
A detection threshold of $5\sigma$ avoids flagging ICL itself as ``sources.''

\begin{codebox}[Step 1: Source Masking]
\begin{lstlisting}[style=bash,numbers=none]
python3 ds9/library/ds9_icl.py $FITS --mode mask \
    --expand-factor 1.5 \
    --max-dilate-radius 20 \
    --detect-thresh 5.0 \
    --bright-star-mag-limit 18.0 \
    --interp-method linear \
    --mask-output  results/montes2022/icl_mask.fits \
    --masked-output results/montes2022/icl_masked.fits
\end{lstlisting}
\end{codebox}

\noindent
This masks ${\sim}32\%$ of pixels---compact enough to leave the ICL intact
but aggressive enough to remove all bright galaxies and stars.

\subsection{Step 2: Background Subtraction}

A 2nd-order 2D polynomial is fitted to the masked image, with iterative
$3\sigma$ clipping over 3 iterations.

\begin{codebox}[Step 2: 2D Polynomial Background]
\begin{lstlisting}[style=bash,numbers=none]
python3 ds9/library/ds9_icl.py $FITS --mode background \
    --mask results/montes2022/icl_mask.fits \
    --bkg-method polynomial \
    --bkg-order 2 \
    --bkg-sigma-clip 3.0 \
    --iterative --bkg-n-iterations 3 \
    --bkg-convergence-tol 0.01 \
    --bkg-output  results/montes2022/icl_background.fits \
    --bgsub-output results/montes2022/icl_bgsub.fits
\end{lstlisting}
\end{codebox}

\subsection{Step 3: Surface Brightness Profile}

Measure the azimuthally-averaged circular SB profile in 51
logarithmically-spaced annuli from $r=3$ to $r=1143$ pixels ($0\rlap{.}{''}2$ to
$72''$, i.e.\ 1--380\,kpc).

\begin{codebox}[Step 3: Circular SB Profile]
\begin{lstlisting}[style=bash,numbers=none]
python3 ds9/library/ds9_icl.py $BGSUB --mode profile \
    --center 1004,1067 \
    --rmin 3.0 --rmax 1143 --nsteps 51 --spacing log \
    --mag-zeropoint auto --pixel-scale 0.063 \
    --profile-output results/montes2022/sb_profile.tsv
\end{lstlisting}
\end{codebox}

\subsection{Step 4: Sector Profiles (East / West)}

Directional profiles in 20$^\circ$-wide sectors along the east and west
semi-major axes, matching the analysis in Figure~2 of \textcite{montes2022}.

\begin{codebox}[Step 4: East and West Sector Profiles]
\begin{lstlisting}[style=bash,numbers=none]
# East sector (PA = 0)
python3 ds9/library/ds9_icl.py $BGSUB --mode profile \
    --center 1004,1067 \
    --rmin 3 --rmax 1143 --nsteps 51 --spacing log \
    --sector-width 20.0 --sector-pa 0.0 \
    --mag-zeropoint auto --pixel-scale 0.063 \
    --profile-output results/montes2022/sb_profile_east.tsv

# West sector (PA = 180)
python3 ds9/library/ds9_icl.py $BGSUB --mode profile \
    --center 1004,1067 \
    --rmin 3 --rmax 1143 --nsteps 51 --spacing log \
    --sector-width 20.0 --sector-pa 180.0 \
    --mag-zeropoint auto --pixel-scale 0.063 \
    --profile-output results/montes2022/sb_profile_west.tsv
\end{lstlisting}
\end{codebox}

\subsection{Step 5: ICL Fraction (Multi-Threshold)}

Compute the ICL fraction $f_\mathrm{ICL}(\mu > \mu_\mathrm{thresh})$ at
thresholds from 25.0 to 29.0\,mag\,arcsec$^{-2}$ with bootstrap error
estimation.

\begin{codebox}[Step 5: Multi-Threshold ICL Fraction]
\begin{lstlisting}[style=bash,numbers=none]
python3 ds9/library/ds9_icl.py $BGSUB --mode measure-multi \
    --profile-file results/montes2022/sb_profile.tsv \
    --mu-min 25.0 --mu-max 29.0 --mu-step 0.5 \
    --n-bootstrap 500 --pixel-scale 0.063 \
    > results/montes2022/icl_fraction_multi.tsv
\end{lstlisting}
\end{codebox}

\subsection{Step 6: BCG+ICL Decomposition}

Fit a double S\'ersic model (BCG + ICL) to the radial profile.

\begin{codebox}[Step 6: Double S\'ersic Decomposition]
\begin{lstlisting}[style=bash,numbers=none]
python3 ds9/library/ds9_icl.py $BGSUB --mode decompose \
    --profile-file results/montes2022/sb_profile.tsv \
    --pixel-scale 0.063 --mag-zeropoint auto \
    > results/montes2022/decompose_result.tsv
\end{lstlisting}
\end{codebox}

\subsection{Step 7: Multi-Band Color Profile (Optional)}

If F090W data is available, measure the radial color gradient.

\begin{codebox}[Step 7: Color Profile (F090W $-$ F277W)]
\begin{lstlisting}[style=bash,numbers=none]
python3 ds9/library/ds9_icl.py $FITS --mode color \
    --mask results/montes2022/icl_mask.fits \
    --center 1004,1067 \
    --bands "F090W:$F090W,F277W:$FITS" \
    --rmin 3 --rmax 1143 --nsteps 51 --spacing log \
    --mag-zeropoint auto --pixel-scale 0.063 \
    > results/montes2022/color_profile.tsv
\end{lstlisting}
\end{codebox}


\section{Results}
\label{sec:example-results}

Figure~\ref{fig:sb-profile} compares the measured SB profile with the
Montes+2022 model composed of a BCG component (de~Vaucouleurs,
S\'ersic $n=4$, $r_e=3''$) and an ICL power-law component with projected
slope $\alpha_\mathrm{proj} = \alpha_\mathrm{3D} + 1 = -1.47$.
Our pipeline recovers the profile from $\mu \approx 18$ to

\chapter{Worked Example: LSBG Detection in DESI Legacy Survey}
\label{ch:example-lsbg}
%======================================================

This chapter demonstrates the complete LSBG (Low Surface Brightness Galaxy)
detection pipeline using ground-based data from the DESI Legacy Survey
DR9~\cite{dey2019}, reproducing the analysis of
\textcite{du2024}.\footnote{Du et~al.\ 2024, RAA 24, 055015 --- ``Low Surface
Brightness Galaxies from BASS+MzLS with Machine Learning''}
We show both the \textbf{command-line} workflow (a self-contained bash script)
and the equivalent \textbf{GUI} workflow using the DS9 LSBG panel.

This complements the ICL worked example (Chapter~\ref{ch:example}) by
demonstrating the LSBG pipeline on ground-based survey data with very
different characteristics from JWST.

\section{Data and Goals}

\begin{itemize}
  \item \textbf{Survey}: DESI Legacy Survey DR9 North (BASS+MzLS)~\cite{dey2019}
  \item \textbf{Pixel scale}: $0\rlap{.}{''}262$/pixel (ground-based)
  \item \textbf{Mag zero-point}: 22.5 (nanomaggy system)
  \item \textbf{Brick}: 2828p530 (RA${}=282\rlap{.}{\circ}8$,
        Dec${}=+53\rlap{.}{\circ}0$)
  \item \textbf{Image}: $3600\times3600$ pixels, $r$-band coadd ($\sim$50\,MB)
  \item \textbf{PSF FWHM}: $\sim1\rlap{.}{''}4$ ($\sim5.3$ pixels)
\end{itemize}

\noindent
The goals are to:
\begin{enumerate}
  \item Detect low surface brightness galaxies by direct image analysis
        (SEP-based detection + S\'ersic fitting)
  \item Compare with the Du+2024 reference catalog constructed from
        Tractor model-fitting photometry + XGBoost classification
  \item Evaluate completeness and contamination of the image-based
        approach versus the catalog-based ML approach
\end{enumerate}

\noindent
Du+2024 selection criteria:
\begin{itemize}
  \item $24.2 < \mu_\mathrm{eff,g} < 28.8$\,mag\,arcsec$^{-2}$
  \item $r_\mathrm{eff} > 2\rlap{.}{''}5$
  \item ellipticity $< 0.7$
  \item Color: $-0.4 < g-r < 1.0$
  \item Quality: $\texttt{fracmasked} < 0.5$, $\texttt{fracflux} < 5$,
        $\texttt{fracin} > 0.3$
\end{itemize}

\begin{remark}
Unlike the ICL pipeline which preserves diffuse light, the LSBG pipeline
\emph{detects} individual extended objects.
The parameter tuning is fundamentally different: lower detection thresholds,
multi-scale analysis, and photometric filtering replace the masking-heavy
ICL approach.
\end{remark}


\section{Parameter Comparison: JWST vs DESI}

The table below highlights why different parameters are needed for
ground-based DESI data versus space-based JWST data.

\begin{center}
\begin{tabular}{L{4.0cm} L{3.0cm} L{3.0cm} L{4.5cm}}
\toprule
\textbf{Parameter} & \textbf{JWST ICL} & \textbf{DESI LSBG} & \textbf{Reason} \\
\midrule
\texttt{pixel-scale}         & 0.063       & 0.262       & NIRCam vs ground-based \\
\texttt{mag-zeropoint}       & auto (26.5) & 22.5        & MJy/sr vs nanomaggies \\
\texttt{detect-thresh}       & $5\sigma$   & $1\sigma$   & ICL preserving vs LSB detecting \\
\texttt{detect-minarea}      & 5 pix       & 100 pix     & HST resolution vs seeing-limited \\
\texttt{detect-filter-kernel} & ---         & gauss7x7   & Larger PSF needs broader kernel \\
\texttt{mu-eff-min}          & ---          & 24.0        & LSBG definition cutoff \\
\texttt{r-eff-min}           & ---          & 2.5\arcsec  & Du+2024 criterion \\
\texttt{multiscale}          & No           & Yes (1,2,4) & Extended diffuse sources \\
\texttt{bkg-mesh-size}       & ---          & 256         & Large-scale gradients \\
\bottomrule
\end{tabular}
\end{center}


\section{CLI Pipeline}
\label{sec:example-lsbg-cli}

The complete analysis is encapsulated in
\texttt{scripts/reproduce\_du2024.sh}.
Below we walk through each step with the exact commands.

\subsection{Step 0: Data Preparation}

Download the DESI DR9 image and construct the reference catalog from the
Tractor photometric database.

\begin{codebox}[Step 0: Fetch data]
\begin{lstlisting}[style=bash,numbers=none]
# Download image + query Tractor catalog + apply Du+2024 cuts
python3 scripts/fetch_du2024_data.py
\end{lstlisting}
\end{codebox}

\noindent
This produces three files:
\begin{itemize}
  \item \texttt{data/desi\_dr9\_2828p530\_r.fits} --- $r$-band coadd ($\sim$50\,MB)
  \item \texttt{data/du2024\_tractor\_2828p530.csv} --- Tractor sources ($r_e > 2.5''$)
  \item \texttt{data/du2024\_reference\_lsbg.csv} --- Reference LSBGs after Du+2024 cuts
\end{itemize}

\subsection{Step 1: Configuration}

\begin{codebox}[Step 1: Parameters]
\begin{lstlisting}[style=bash,numbers=none]
PIXEL_SCALE=0.262     # arcsec/pixel (ground-based)
MAG_ZP=22.5           # nanomaggy zeropoint
DETECT_THRESH=1.0     # low threshold for LSB detection
DETECT_MINAREA=100    # ~27 arcsec^2 (PSF ~1.4" FWHM)
FILTER_KERNEL=gauss7x7  # broader kernel for larger PSF
MU_EFF_MIN=24.0       # LSBG cutoff
MU_EFF_MAX=29.0       # faint limit
R_EFF_MIN=2.5         # arcsec (Du+2024 criterion)
R_EFF_MAX=60.0        # arcsec
ELLIPTICITY_MAX=0.7   # Du+2024 criterion
MASK_THRESH=1.5       # source masking threshold
MASK_MAG_THRESH=22.0  # only mask bright sources
\end{lstlisting}
\end{codebox}

\begin{remark}
The detection threshold is set to $1\sigma$ --- much lower than the
$5\sigma$ used for ICL source masking. This is because we \emph{want}
to detect faint extended objects, not avoid them.
The larger \texttt{detect-minarea} (100 vs 5 pixels) compensates for the
lower threshold by requiring spatially coherent detections.
\end{remark}

\subsection{Step 2: Full Pipeline}

The LSBG pipeline runs all steps (masking, background, detection,
photometry, S\'ersic fitting, filtering) in a single command.

\begin{codebox}[Step 2: Run full pipeline]
\begin{lstlisting}[style=bash,numbers=none]
python3 ds9/library/ds9_lsbg.py $FITS --mode run \
    --pixel-scale 0.262 \
    --mag-zeropoint 22.5 \
    --mask-detect-thresh 1.5 \
    --mask-mag-threshold 22.0 \
    --mask-expand-factor 1.5 \
    --max-dilate-radius 30 \
    --lsb-protect --lsb-mu-threshold 24.0 \
    --bkg-method sep_large \
    --bkg-mesh-size 256 \
    --bkg-n-iterations 3 \
    --bkg-convergence-tol 0.01 \
    --detect-thresh 1.0 \
    --detect-minarea 100 \
    --detect-filter-kernel gauss7x7 \
    --multiscale --multiscale-factors 1,2,4 \
    --mu-eff-min 24.0 --mu-eff-max 29.0 \
    --r-eff-min 2.5 --r-eff-max 60.0 \
    --ellipticity-max 0.7 \
    --sersic-fit \
    --catalog-output results/du2024/lsbg_detected.tsv \
    --mask-output results/du2024/lsbg_mask.fits \
    --cleaned-output results/du2024/lsbg_cleaned.fits \
    --segmap-output results/du2024/lsbg_segmap.fits
\end{lstlisting}
\end{codebox}

\noindent
The pipeline internally executes:
\begin{enumerate}
  \item \textbf{Masking}: Detect sources above $1.5\sigma$ with magnitude
        $< 22.0$; dilate masks while protecting LSB structures
        ($\mu > 24$\,mag\,arcsec$^{-2}$)
  \item \textbf{Background}: Iterative SEP mesh-based background with
        256-pixel mesh, 3 iterations, lower-quantile RMS for sensitivity
  \item \textbf{Detection}: Multi-scale detection at $1\times$, $2\times$,
        $4\times$ rebinning, merged into a unified source list
  \item \textbf{Photometry}: Kron elliptical + multi-aperture photometry;
        surface brightness and effective radius calculation
  \item \textbf{S\'ersic fitting}: 2D radial profile fitting per source
  \item \textbf{Filtering}: Apply $\mu_\mathrm{eff}$, $r_\mathrm{eff}$,
        ellipticity, SNR, and S\'ersic quality cuts;
        assign A/B/C/D confidence grades
\end{enumerate}

\subsection{Step 3: Comparison}

Compare detected LSBGs with the Du+2024 reference catalog.

\begin{codebox}[Step 3: Generate comparison figures]
\begin{lstlisting}[style=bash,numbers=none]
python3 scripts/compare_du2024.py
\end{lstlisting}
\end{codebox}

\section{Catalog Panel Procedures}

\subsection{CreateCatalogPanel}

Creates all widgets for the catalog panel within \texttt{ds9(catalog\_frame)}:

\begin{center}
\begin{longtable}{L{3.5cm} L{9.5cm}}
\toprule
\textbf{Widget} & \textbf{Description} \\
\midrule
\endhead
\texttt{titlebar} & Horizontal frame containing the ``Source Extractor'' label, ``Extract'' button, and ``Clear'' button. \\
\midrule
\texttt{searchbar} & Filter entry with ``Apply'' button. The entry is bound to \texttt{<Return>} for keyboard activation. \\
\midrule

\midrule

\bottomrule
\end{longtable}
\end{center}

\subsection{CatalogPanelExtract}

Orchestrates the extraction process:

\begin{enumerate}[leftmargin=2em]
  \item Locates the \sextract{} binary in the same directory as the DS9 executable
  \item Retrieves the current FITS filename from the active frame
  \item Constructs \texttt{LD\_LIBRARY\_PATH} to include conda libraries (both \texttt{\$CONDA\_PREFIX/lib} and \texttt{\$HOME/miniconda3/lib})
  \item Executes \sextract{} via \texttt{exec sh -c} and captures stdout
  \item Passes the TSV output to \texttt{CatalogPanelLoadTSV}
\end{enumerate}

\subsection{CatalogPanelLoadTSV}

Parses tab-separated data into the Tktable widget:

\begin{enumerate}[leftmargin=2em]
  \item Splits the input string by newlines into rows
  \item Parses the first row as column headers
  \item Configures the table dimensions (\texttt{-cols}, \texttt{-rows})
  \item Fills the \texttt{catpaneltbldb} array variable: \texttt{catpaneltbldb(\textit{row},\textit{col})}
  \item Stores the raw data in \texttt{catpanel(alldata)} for filtering
\end{enumerate}

\subsection{CatalogPanelFilter}

Performs case-insensitive substring filtering:

\begin{enumerate}[leftmargin=2em]
  \item Reads the filter pattern from \texttt{catpanel(search\_var)}
  \item Iterates over stored data rows (\texttt{catpanel(alldata)})
  \item Includes a row if the pattern appears anywhere in the tab-separated line (\texttt{string match -nocase})

\section{FITS File Handling}

The FITS reader searches for a 2D image HDU in the following order:

\begin{enumerate}[leftmargin=2em]
  \item Iterate through all HDUs; use the first one with 2D data (\texttt{hdu.data.ndim == 2})
  \item If no 2D HDU is found, try the primary HDU
  \item If the primary has $>2$ dimensions, extract the first 2D slice (\texttt{data[0]})
  \item The data is converted to \texttt{float64} C-contiguous format (required by SEP)
\end{enumerate}

\section{Marker Click --- Image to Catalog Navigation}

Clicking a yellow ellipse marker in the image navigates the catalog to the corresponding source.

\subsection{Implementation}

DS9's built-in \texttt{highlite} callbacks only fire in \texttt{catalog} mode. Since the default viewing mode is \texttt{none}, explicit click handlers were added in \texttt{frame.tcl}:

\begin{codebox}[frame.tcl --- Button1Frame (none mode)]
\begin{lstlisting}[style=tcl,numbers=none]
none {
    if {$which == $current(frame)} {
        CatalogPanelMarkerClick $which $x $y
    } else {
        ...
    }
}
\end{lstlisting}
\end{codebox}

The click detection uses DS9's marker API:

\begin{codebox}[CatalogPanelMarkerClick]
\begin{lstlisting}[style=tcl,numbers=none]
proc CatalogPanelMarkerClick {which x y} {
    set id [$which get marker catalog id $x $y]
    if {$id == 0} return
    set tags [$which get marker catalog $id tag]
    foreach tag $tags {
        if {[string match "sextract_src.*" $tag]} {
            set src_num [string range $tag 13 end]
            break
        }
    }
    CatalogPanelMarkerCB $src_num $id
}
\end{lstlisting}
\end{codebox}

\texttt{CatalogPanelMarkerCB} then:
\begin{enumerate}[leftmargin=2em]
  \item Finds the \texttt{NUMBER} column in the table header
  \item Searches all rows for the matching source number
  \item Selects the row and scrolls the table to it
  \item Calls \texttt{CatalogPanelGotoSource} to pan the image and show selection markers (cyan cross + green ellipse)
\end{enumerate}


\section{Visible Filter}

The \textbf{Visible} button toggles between showing all sources and showing only sources within the current viewport.

\subsection{Viewport Calculation}

\begin{codebox}[Viewport bounds computation]
\begin{lstlisting}[style=tcl,numbers=none]
set center [$frame get cursor image]   ;# {cx cy}
set zoom   [$frame get zoom]           ;# {zx zy}
set cw [winfo width $ds9(canvas)]
set ch [winfo height $ds9(canvas)]
set x_min [expr {$cx - $cw / 2.0 / $zx}]
set x_max [expr {$cx + $cw / 2.0 / $zx}]
set y_min [expr {$cy - $ch / 2.0 / $zy}]
set y_max [expr {$cy + $ch / 2.0 / $zy}]
\end{lstlisting}
\end{codebox}

Sources with \texttt{X\_IMAGE} and \texttt{Y\_IMAGE} within these bounds are displayed. The status bar shows ``Visible: N of M sources in current view.''


\section{Source Merging (Ctrl+Click + Ctrl+M)}

Multiple sources can be merged into a single source through a two-step process.

\subsection{Step 1: Select Merge Candidates}

\textbf{Ctrl+Click} on a yellow ellipse marker toggles it as a merge candidate:
\begin{itemize}[leftmargin=2em]
  \item Selected: A red thick ellipse (\texttt{width=3}) is overlaid, tagged \texttt{sextract\_merge} and \texttt{sextract\_merge.\textit{NUMBER}}
  \item Deselected: Ctrl+Click again removes the red marker and the source from the merge list
  \item Status bar: ``Merge: N sources selected (Ctrl+M to merge, Esc to cancel)''
\end{itemize}

\subsection{Step 2: Execute Merge (Ctrl+M)}

When at least 2 sources are selected, \textbf{Ctrl+M} merges them:

\begin{center}
\begin{longtable}{L{3.2cm} L{9.3cm}}
\toprule
\textbf{Property} & \textbf{Merge Algorithm} \\
\midrule
\endhead
\texttt{X\_IMAGE}, \texttt{Y\_IMAGE} & Flux-weighted centroid: $\bar{x} = \sum F_i x_i / \sum F_i$ \\
\midrule
\texttt{FLUX\_AUTO} & Sum of all fluxes: $F_{\text{total}} = \sum F_i$ \\
\midrule
\texttt{MAG\_AUTO} & Recomputed: $m = -2.5\log_{10}(F_{\text{total}}) + m_0$ \\
\midrule
\texttt{NPIX\_ISO} & Sum of all pixel counts \\
\midrule
\texttt{ISO\_RADIUS} & $r = \sqrt{N_{\text{pix,total}} / (\pi \cdot b/a)}$ \\
\midrule
\texttt{A\_IMAGE}, \texttt{B\_IMAGE}, \texttt{THETA\_IMAGE} & Flux-weighted average \\
\midrule
\texttt{NUMBER} & New number: $\max(\text{all NUMBERs}) + 1$ \\
\midrule
Other columns & Copied from the brightest source \\
\bottomrule
\end{longtable}
\end{center}

After merging:
\begin{enumerate}[leftmargin=2em]
  \item The original sources are removed from \texttt{catpanel(alldata)}
  \item The merged source row is appended
  \item The table and markers are regenerated
  \item The merged source is auto-selected and the image pans to its position
  \item Status bar: ``Merged N sources into \#NEW: pos=(X,Y) mag=M''
\end{enumerate}

\subsection{Cancel (Escape)}

Pressing \textbf{Escape} cancels the merge selection, removes all red markers, and clears the merge list.

\section{Add Objects (Click + A)}

The Add Objects feature enables manual detection and addition of individual sources that were missed by the automatic extraction. This is useful for faint sources near the detection threshold or sources in complex environments (e.g., near bright stars, in galaxy halos, or at the edge of the field).

\subsection{Activation}

Enable via \textbf{Display $\to$ Add Objects (Click + A)}. This toggles a checkbutton in the Display menu; when enabled, the \texttt{a} key triggers source addition.

\subsection{Workflow}

\begin{enumerate}[leftmargin=2em]
  \item Enable ``Add Objects'' in the Display menu.
  \item Click on an empty area of the image where a source should be detected.
  \item Press \texttt{a}. The system:
  \begin{enumerate}
    \item Saves the FITS image to a temporary file.
    \item Runs \texttt{ds9\_add\_source.py} with the saved image coordinates.
    \item Extracts a $25 \times 25$ pixel cutout centered on the click position.
    \item Runs SEP detection with aggressive parameters (threshold $0.8\sigma$, min area 3~px).
    \item Finds the nearest detected source within 10\,px of the click position.
    \item Appends the source to the catalog and regenerates markers.
  \end{enumerate}
  \item The status bar shows the new source's NUMBER and position.
\end{enumerate}

\subsection{Detection Parameters}

Add Objects uses more aggressive detection parameters than the standard extraction to maximize sensitivity near the click position:

\begin{center}
\begin{tabular}{lcc}
\toprule
\textbf{Parameter} & \textbf{Standard} & \textbf{Add Objects} \\
\midrule
Detect threshold & $1.5\sigma$ & $0.8\sigma$ \\
Minimum area & 5\,px & 3\,px \\
Deblend nthresh & 32 & 64 \\
Deblend mincont & 0.005 & 0.0001 \\
Cutout radius & full image & 25\,px \\
Max distance & --- & 10\,px \\
\bottomrule
\end{tabular}
\end{center}

\section{Source Separation (Click + S)}

The Separate feature deblends a selected source into multiple sub-components using SEP with aggressive deblending parameters. This is essential for resolving blended sources in crowded fields or merging galaxies.

\subsection{Workflow}

\begin{enumerate}[leftmargin=2em]
  \item Click on a source's ellipse marker to select it.
  \item Press \texttt{s}. The system:
  \begin{enumerate}
    \item Reads the selected source's position, shape (A\_IMAGE, B\_IMAGE, THETA\_IMAGE), and ISO\_RADIUS.
    \item Saves the FITS image temporarily.
    \item Runs \texttt{ds9\_separate.py} with the source parameters.
    \item Extracts a cutout of radius $3 \times \max(a, b)$ around the source.
    \item Runs SEP with aggressive deblending (nthresh=64, mincont=0.0001).
    \item Filters sub-sources to keep only those within the parent's ellipse region.
    \item If $\geq 2$ sub-components are found, replaces the parent row with sub-source rows.
  \end{enumerate}
  \item Sub-sources are numbered as \texttt{parent.1}, \texttt{parent.2}, etc.
\end{enumerate}

\subsection{Brightest Sub-Source Shape Preservation}

The brightest sub-source (by flux) retains the parent's original ellipse parameters:
\begin{itemize}[leftmargin=2em]
  \item \texttt{A\_IMAGE}, \texttt{B\_IMAGE}, \texttt{THETA\_IMAGE} --- copied from parent
  \item \texttt{ISO\_RADIUS} --- copied from parent (ensures correct marker rendering)
\end{itemize}

This preserves the morphological characterization of the dominant component while splitting off fainter companions with independently measured shapes.

\chapter{Advanced Analysis Features}
\label{ch:analysis}
%======================================================

The \textbf{Analysis} menu provides advanced photometric, morphological, and catalog analysis tools implemented as Python scripts. Each tool reads the current catalog and FITS image, performs its analysis, and appends result columns to the catalog table.

\section{Non-Parametric Morphology (CAS/Gini/M20)}

Measures five non-parametric morphological indices for each source, following the definitions of Conselice (2003), Lotz et~al.\ (2004), and Petrosian (1976).

\begin{center}
\begin{longtable}{L{2.8cm} L{9.5cm}}
\toprule
\textbf{Index} & \textbf{Definition} \\
\midrule
\endhead
\texttt{CONC} & Concentration index: $C = 5\log_{10}(r_{80}/r_{20})$, where $r_{80}$ and $r_{20}$ are the circular radii enclosing 80\% and 20\% of the total flux (computed via \texttt{sep.flux\_radius}). \\
\midrule
\texttt{ASYM} & Asymmetry: $A = \min\!\bigl(\sum|I - I_{180}|\bigr) / (2\sum|I|)$, where $I_{180}$ is the image rotated 180\textdegree{} about the center. The center is optimized to minimize $A$. \\
\midrule
\texttt{GINI} & Gini coefficient of the pixel intensity distribution within the segmentation footprint: $G = \frac{1}{\bar{x}\,n(n-1)}\sum_{i=1}^{n}(2i - n - 1)\,x_i$, where $x_i$ are the sorted pixel values. \\
\midrule
\texttt{M20} & $M_{20} = \log_{10}\!\bigl(\sum_{i} f_i r_i^2 \text{ (brightest 20\%)} / \sum_{i} f_i r_i^2\bigr)$, a second-order moment of the brightest 20\% of pixels. \\
\midrule
\texttt{R\_PETRO} & Petrosian radius: the radius $r$ where $\eta(r) = I(r)/\langle I(<r)\rangle = 0.2$, computed from concentric circular annuli. \\
\bottomrule
\end{longtable}
\end{center}

\textbf{Package}: \texttt{morphometry/} --- modules: \texttt{concentration.py}, \texttt{asymmetry.py}, \texttt{gini.py}, \texttt{m20.py}, \texttt{petrosian.py}, \texttt{measure.py}.

\textbf{CLI}: \texttt{ds9\_morphometry.py FITSFILE --catalog catalog.tsv [--min-npix 100]}

\textbf{Dependencies}: \texttt{sep}, \texttt{scipy.ndimage}, \texttt{astropy.io.fits}


\section{S\'ersic Profile Fitting}

Fits a 2D S\'ersic profile to each source:

\begin{equation}
I(r) = I_e \exp\!\Bigl[-b_n\Bigl(\bigl(r/r_e\bigr)^{1/n} - 1\Bigr)\Bigr]
\end{equation}

where $n$ is the S\'ersic index, $r_e$ is the effective (half-light) radius, $I_e$ is the intensity at $r_e$, and $b_n \approx 2n - 1/3 + 4/(405n)$.

\begin{center}
\begin{longtable}{L{3.2cm} L{9.0cm}}
\toprule
\textbf{Column} & \textbf{Description} \\
\midrule
\endhead
\texttt{SERSIC\_N} & S\'ersic index $n$ (constrained $0.2 < n < 10$). $n=1$: exponential disk, $n=4$: de~Vaucouleurs profile. \\
\midrule
\texttt{SERSIC\_RE} & Effective radius $r_e$ in pixels. \\
\midrule
\texttt{SERSIC\_IE} & Surface brightness at $r_e$. \\
\midrule
\texttt{SERSIC\_ELLIP} & Fitted ellipticity $e = 1 - b/a$. \\
\midrule
\texttt{SERSIC\_THETA} & Position angle of the fitted ellipse (degrees). \\
\midrule
\texttt{SERSIC\_CHI2} & Reduced $\chi^2$ of the fit. \\
\bottomrule
\end{longtable}
\end{center}

The fitting uses \texttt{scipy.optimize.least\_squares} (Levenberg--Marquardt) with 8 free parameters: $I_e$, $r_e$, $n$, $x_c$, $y_c$, ellipticity, $\theta$, and background level.

\textbf{Package}: \texttt{sersic\_fit/} --- modules: \texttt{models.py}, \texttt{fitter.py}, \texttt{utils.py}.

\textbf{CLI}: \texttt{ds9\_sersic.py FITSFILE --catalog catalog.tsv [--max-sources 200]}


\section{PSF Photometry}

Performs point-source PSF photometry by fitting a scaled, shifted PSF model to each source.

For each source, the model is:
\begin{equation}
M(x,y) = A \cdot \text{PSF}(x - x_0 - \Delta x,\; y - y_0 - \Delta y) + B
\end{equation}

The four free parameters ($A$, $\Delta x$, $\Delta y$, $B$) are optimized via \texttt{scipy.optimize.least\_squares}. The fitted flux is $F_\text{PSF} = A \cdot \sum\text{PSF}$.

\begin{center}
\begin{tabular}{ll}
\toprule
\textbf{Column} & \textbf{Description} \\
\midrule
\texttt{FLUX\_PSF} & PSF-fitted flux \\
\texttt{FLUXERR\_PSF} & $1\sigma$ flux error from covariance \\
\texttt{MAG\_PSF} & PSF magnitude \\
\texttt{MAGERR\_PSF} & PSF magnitude error \\
\texttt{CHI2\_PSF} & Reduced $\chi^2$ of the PSF fit \\
\texttt{X\_PSF}, \texttt{Y\_PSF} & Refined centroid from the fit \\
\bottomrule
\end{tabular}
\end{center}

\textbf{Prerequisite}: A PSF image must exist (generated via Reconstruction $\to$ Build PSF, stored as \texttt{\textasciitilde/.ds9/psf\_current.fits}).

\textbf{Package}: \texttt{psf\_phot/} --- modules: \texttt{fitter.py}, \texttt{photometry.py}, \texttt{subtract.py}.

\textbf{CLI}: \texttt{ds9\_psf\_phot.py FITSFILE --catalog cat.tsv --psf psf.fits}


\section{Multi-Band Photometry}

Performs matched-aperture photometry across multiple filter images using source positions detected in a single reference (detection) image.

\begin{enumerate}[leftmargin=2em]
  \item Source positions and shapes are determined from the detection image (or existing catalog).
  \item For each band image, Kron elliptical and circular aperture photometry is performed at the same positions.
  \item Per-band columns are added: \texttt{FLUX\_AUTO\_\textit{BAND}}, \texttt{MAG\_AUTO\_\textit{BAND}}, \texttt{FLUX\_APER\_\textit{BAND}}, etc.
  \item Color indices are computed automatically: \texttt{COLOR\_\textit{B1}\_\textit{B2}} $= m_{B1} - m_{B2}$.
\end{enumerate}

A dialog allows adding bands by name and FITS file path.

\textbf{CLI}: \texttt{ds9\_multiband.py --detect-image deep.fits --bands F435W:f435w.fits,F606W:f606w.fits}


\section{Crowded Field Photometry (DAOPHOT-Style)}

Implements iterative multi-PSF fitting for crowded stellar fields, following the DAOPHOT approach (Stetson 1987):

\begin{enumerate}[leftmargin=2em]
  \item \textbf{Grouping}: Sources with overlapping Kron radii are assigned to the same group using adjacency-based graph clustering.
  \item \textbf{Simultaneous fitting}: For each group, all $N$ source PSFs are fitted simultaneously by minimizing:
  \begin{equation}
    \chi^2 = \sum_\text{pixels} \Bigl(I_\text{data} - \sum_{j=1}^N A_j \cdot \text{PSF}(x - x_j, y - y_j) - B\Bigr)^2
  \end{equation}
  with $3N + 1$ free parameters ($A_j$, $\Delta x_j$, $\Delta y_j$ per source, plus background $B$).
  \item \textbf{Subtraction}: Fitted PSFs are subtracted from the image.
  \item \textbf{Re-detection}: New sources are detected in the residual image.
  \item Steps 1--4 are repeated for a configurable number of iterations (default: 3).
\end{enumerate}

\begin{center}
\begin{tabular}{ll}
\toprule
\textbf{Column} & \textbf{Description} \\
\midrule
\texttt{FLUX\_CROWD} & Multi-PSF fitted flux \\
\texttt{FLUXERR\_CROWD} & $1\sigma$ flux error \\
\texttt{MAG\_CROWD} & Crowded-field magnitude \\
\texttt{X\_CROWD}, \texttt{Y\_CROWD} & Refined positions \\
\texttt{N\_NEIGHBORS} & Number of sources in the fitting group \\
\bottomrule
\end{tabular}
\end{center}

\textbf{Prerequisite}: A PSF image must exist.

\textbf{Package}: \texttt{crowded\_phot/} --- modules: \texttt{group.py}, \texttt{nstar.py}, \texttt{psf\_subtract.py}, \texttt{iterate.py}.

\textbf{CLI}: \texttt{ds9\_crowded\_phot.py FITSFILE --catalog cat.tsv --psf psf.fits [--max-iter 3]}


\section{Catalog Cross-Match (VizieR)}

Cross-matches the current catalog against external reference catalogs hosted on VizieR using TAP/ADQL queries.

\subsection{Supported Catalogs}

\begin{center}
\begin{tabular}{lll}
\toprule
\textbf{Name} & \textbf{VizieR ID} & \textbf{Contents} \\
\midrule
Gaia DR3 & I/355/gaiadr3 & Astrometry + photometry \\
2MASS & II/246/out & Near-infrared $JHK_s$ \\
Pan-STARRS DR1 & II/349/ps1 & Optical $grizy$ \\

AllWISE & II/328/allwise & Mid-infrared $W1$--$W4$ \\

\subsection{Algorithm}

\begin{enumerate}[leftmargin=2em]
  \item Extract \texttt{ALPHA\_J2000} and \texttt{DELTA\_J2000} from the current catalog.
  \item Compute the field center and search radius.
  \item Query VizieR via TAP: \texttt{SELECT * FROM "catalog" WHERE 1=CONTAINS(POINT('ICRS',RA,DEC), CIRCLE('ICRS',$\alpha_c$,$\delta_c$,$r$))}.
  \item Match each source to the nearest catalog entry within the specified radius (default: 2\,arcsec).
  \item Append columns: \texttt{MATCH\_ID}, \texttt{MATCH\_DIST}.
\end{enumerate}

A dialog allows selecting the catalog and matching radius.

\textbf{CLI}: \texttt{ds9\_crossmatch.py --catalog cat.tsv --vizier-cat II/349 --radius 2.0}

\textbf{Requirement}: \texttt{ALPHA\_J2000} and \texttt{DELTA\_J2000} must be present (requires WCS in the FITS header).


\section{Dual-Image Mode}

Performs source detection on one image and photometric measurement on another, following the SExtractor dual-image paradigm. This is essential for multi-band surveys where consistent source definitions are needed across filters.

\begin{enumerate}[leftmargin=2em]
  \item Source detection (\texttt{sep.extract}) is run on the \textbf{detection image} (typically a deep or stacked image).
  \item Kron radius, aperture photometry, and shape measurements are performed on the \textbf{measurement image} at the detected positions.
  \item The output catalog uses detection-image positions with measurement-image fluxes and magnitudes.
\end{enumerate}

A dialog allows selecting the detection and measurement images from open DS9 frames or FITS files.

\textbf{CLI}: \texttt{ds9\_dual\_extract.py --detect-image deep.fits --measure-image filter.fits}


\section{Segmentation Map}

Generates a segmentation map where each pixel is labeled with the ID of the source it belongs to (0 = background). The result is loaded as a new DS9 frame with a random colormap for visualization.

\textbf{CLI}: \texttt{ds9\_segmap.py FITSFILE [--detect-thresh 1.5] [--output \textasciitilde/.ds9/segmap.fits]}


\section{Completeness Simulation}

Estimates detection completeness as a function of magnitude by injecting artificial sources and attempting to recover them:

\begin{enumerate}[leftmargin=2em]
  \item Inject $N$ artificial PSF sources at random positions (avoiding existing sources), distributed uniformly in magnitude bins from $m_\text{min}$ to $m_\text{max}$.
  \item Re-run source extraction with the same parameters.
  \item Cross-match injected and recovered sources ($< 2$\,pixel separation).
  \item Compute completeness per magnitude bin: $C(m) = N_\text{recovered} / N_\text{injected}$.
\end{enumerate}

Output: \texttt{MAG\_BIN \textbackslash t N\_INJECTED \textbackslash t N\_RECOVERED \textbackslash t COMPLETENESS}

A dialog allows configuring the number of injected sources, magnitude range, and number of bins.

\textbf{CLI}: \texttt{ds9\_completeness.py FITSFILE [--n-inject 1000] [--mag-min 20] [--mag-max 28]}

# 검증 계획 — 예제, 실행 결과 아님

- 격리 호스트가 새 출력 디렉터리를 만들고 `inputs={'values': fixture 경로}`,
  `params={}`로 `run`을 호출한다. 기존 파일이 있는 출력 폴더를 재사용하지 않는다.
- 입력 JSON `[1, 2, 3]`: result.json의 count=3, mean=2.0 (절대 오차 1e-12).
- 입력 `[]`, `[true]`, `["3"]`, `null`, `[NaN]`: ValueError, 완료 산출물 없음.
- 입력 파일 SHA-256이 실행 전후 동일해야 한다.
- import만으로 출력 파일·네트워크 활동이 없어야 한다.
- 브라우저 대상이면 실제 고정 WASM 런타임에서 동일 값/오류를 비교한다.
- 시간 제한·취소·저장/복원 시험은 등록 호스트 통합 시 별도 수행한다.

사용자 AI는 실제 도구에 맞춰 이 계획을 수정하고 합성 fixture, 기대 결과,
오차 근거와 실행 명령을 추가한다. 시험 결과는 별도 항목으로 기록한다.

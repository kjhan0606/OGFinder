# S23B 고정 지지 weak-lensing 표본 선택 점검 (2026-11-11)

## 범위

승인된 80개 렌즈 manifest와 해시가 고정된 반경별 지지표만 사용해, 7개 annulus 전체에서 target 지지와 최소 4/5 matched control 지지를 갖는 52개 렌즈가 나머지 표본과 어떤 차이가 있는지 비교했다. 원시 source CSV와 영상은 다시 읽지 않았고, CAS·네트워크 요청이나 다운로드도 하지 않았다. 이 점검은 전단 또는 질량 측정이 아니며 `science_measurement=false`다.

비교군은 통합 0.1–3 proper-Mpc 기준으로 지지가 인정된 74개 중 고정 52개에 들지 않은 22개다. 초기 manifest의 나머지 6개는 이 74개 부모 표본에 포함되지 않는다.

## 해석

선택된 52개와 나머지 22개는 redshift 분포가 비슷하다. 반면 52개 표본의 중앙 CAMIRA 풍부도는 더 낮고, pre-cut S19A 형상원 수 중앙값은 약 61% 높다. 이 source 수는 원시 catalog 가용성의 대리량이지 깊이 보정 지도는 아니지만, 고정 표본이 관측 지지에 따라 선택됐음을 보여준다.

따라서 52개 stack은 해당 지지 표본에 대한 분석에는 쓸 수 있어도, 선택 보정 없이 전체 S23B 은하단의 대표 결과로 일반화하면 안 된다. 특히 ICL–weak-lensing 연관성을 전체 표본에 적용하려면 선택 모델을 포함하거나 공통 52개 표본으로 결론의 범위를 제한해야 한다. 계수별 HSC 선택보정 민감도가 공간 잭나이프 오차보다 작다는 결과는 이 표본 선택 차이를 보정하지 않는다.

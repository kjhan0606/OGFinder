## 확보한 자료와 출처

Garate-Nuñez et al. (2024), *The Hyper Suprime-Cam extended Point Spread Functions
and applications*의 [논문](https://arxiv.org/abs/2309.16244)과
[저자 저장소](https://github.com/luciagarate/HSC_PSFs)가 연결한
[Zenodo 데이터셋, DOI 10.5281/zenodo.14915578](https://zenodo.org/records/14915578)을 사용했다.
논문은 최종 국소 하늘 차감 전의 `coadd/bg` 자료에 대한 참조 PSF를 설명한다.
위치·시상·관측 epoch가 개별 연구 영상과 일치한다는 보증은 아니다.

| 실제 확보 파일 | 크기 | 배포본 MD5 |
|---|---:|---|
| `HSC_PSF_i.fits` | 9,809,280 bytes | `5bf3317bcc41a83c81c25acab2faab09` |
| `HSC_PSF_i_asymmetric.fits` | 9,809,280 bytes | `665e7b459cda203d6610133c3626194d` |

두 FITS 합계는 약 **18.71 MiB**다. 설명 README와 배포 메타데이터도 보존했다.
`prepare_extended_psf.py`가 파일 크기와 고정한 배포 MD5를 대조하고 SHA-256을
별도로 기록한다. 배포 메타데이터의 라이선스는 **CC-BY-4.0**이며 저자·논문·DOI를
`summary.json`에 명시했다. 외부 R 스크립트를 실행하거나 애플리케이션에 편입하지
않았고 자료는 `/gpfs/kjhan/Astrafek/data`에 둔다.

각 영상은 HDU 1의 4001×4001 배열이다. 중앙 최대값과 유한한 픽셀을 확인했고
전체 픽셀 합은 대칭본 1.0000000114, 비대칭본 0.9999999970이다.
픽셀 척도 0.168초각은 논문에 근거하며, 배포 FITS 헤더에 없는 WCS를 만들어내지
않았다. 내접 원 반경은 336초각(5.6각분)이다.

대칭본의 유한한 배포 격자 합 대비 누적 광량은 다음과 같다.

| 반경 | 격자 합 대비 누적 광량 |
|---|---:|
| 2.016초각 | 92.50% |
| 6초각 | 96.82% |
| 16.128초각 | 98.38% |
| 60초각 | 99.34% |
| 120초각 | 99.73% |

무한 반경 총광량에 대한 비율이나 해당 은하단 영상의 실측 구경 보정값은 아니다.
배포 배열에는 음수 픽셀도 대칭본 937,824개, 비대칭본 937,556개 있다.
원본 부호를 보존했고 양수로 잘라 임의의 PSF 커널을 만들지 않았다.

## 관측 프로필과 같은 연산으로 비교

`compare_extended_psf.py`는 배포 PSF의 1픽셀 폭 고리 평균을 구하고 원래 HSC
검출 중심의 subpixel 반경으로 보간한 **방사 대칭 참조 템플릿**을 만든다.
이는 원본 2차원 비등방성을 보존한 적합이 아니다. 대칭본·비대칭본은 원래 별
자료를 공유하고 고리 평균도 거의 같으므로 두 독립 실험으로 세지 않는다.
파생 템플릿은 원본과 별도로 저장하고 변환 방식·해시를 기록했다.

기존 별 32개의 실패 사유를 그대로 보존한다. 우표가 있는 20개에서 각 참조
모형에 Kron 2.5/3.5와 배경 고리 120–150/160–190픽셀을 적용한다. 관측과 참조에
동일한 유효 픽셀, 8방향 평균 배경, 반경 12픽셀 중심 구경을 쓴다. 템플릿을
잘라낸 배열의 합으로 다시 1로 정규화하지 않는다.

관측 중심 광량을 F, 배경 연산을 통과한 참조 중심 광량을 T라고 하면 참조의
진폭은 F/T다. 고리의 참조 예측은 `F/T × (참조 고리 평균 − 참조 배경)`이다.
따라서 날개를 포함한 참조 자체에도 동일한 배경 손실을 적용하고 비교한다.

두 참조 합계 256개 방법 기록 중 진단 가능 60개, 배경 면적 부족 98개,
영상 경계 96개, 중심 마스크 실패 2개다. 이전의 관측 성공 30개를 참조 2종에
대조한 것이며 새로운 별 60개를 확보한 것이 아니다. 방사 비교는 660행이다.

64–96픽셀(10.752–16.128초각) 고리에서 면적 조건을 통과한 25개 방법 기록을
참조 모형별로 비교하면 다음과 같다. 같은 별의 반복 방법이 포함된다.

| 진단량 | 최솟값 | 중앙값 | 최댓값 |
|---|---:|---:|---:|
| 참조 날개 평균에서 배경 추정이 제거하는 비율 | 10.32% | 26.54% | 28.39% |
| 남는 참조 신호 / 관측의 명목 고리 평균 오차 | 0.210 | 0.416 | 0.709 |

두 모형의 값은 표시 자릿수에서 같다. 참조 예측은 25건 모두 양수지만 관측
고리 평균은 23건에서 0 이하다. 참조 모형 기준으로 이 배경 연산만으로 날개가
음수가 되지는 않는다. 다만 이것으로 관측의 음수 잔차 원인을 하나로 특정할 수
없다. 낮은 신호, 실제 하늘·주변 천체 잔차, 검출/마스크 선택, 모형 불일치가 남는다.

명목 오차는 `sqrt(sum(variance))/N`이며 배경·중심 정규화·coadd 공분산을 포함하지
않는다. 위 비율은 검출 유의도가 아니다. 현재 별 표본에서 보이는 약한 날개를
그대로 확정하거나 공개 평균 PSF를 800개 전체의 정답으로 편입하지 않는다.

## 신호 추가 시험과 독립 검산

각 성공 조건에서 원본 별 영상에 참조 템플릿을 더했다. 추가량은 기존 관측 중심
광량의 0.25/1/4배가 회수되도록 설정했다. 전후 고리 평균 차이를 독립적인
선형 배경 연산 예측과 비교했다. **분산과 마스크를 고정하고 photon noise는
추가하지 않은 연산 검증**이다. HSC의 upstream sky 처리, 재검출, 별 선택의
완전성, 경험적 PSF 정확도를 검증한 주입 실험은 아니다.

660개 고리×3진폭=1,980개 기록에서 예상 증분과 측정 증분의 최대 절대 차이는
약 8.53e-14 native flux/pixel이다. `audit_extended_psf.py`는 측정 함수를 호출하지
않고 원본 참조 FITS의 고리를 직접 선택하여 방사 평균·템플릿·배경·정규화를
다시 계산했다. 입력 해시 31건, 원본 배포 MD5, 방사 비교 660건, 추가 신호
1,980건을 검산해 통과했다. 독립 템플릿 픽셀 최대 차이는 1.21e-17,
증분의 독립 계산 최대 오차는 5.68e-14다.

신규 테스트 6건과 기존 경험적 PSF 회귀 4건도 통과했다. 중심/합/유한성 검사,
음수 보존, 잘라낸 템플릿의 임의 정규화 차단, 추가 신호 회수, 불완전 배경 차단,
픽셀 경계 판정과 기존 downloader의 상대 파일 경로 해석을 확인했다.

### 800개 target coadd의 PSF-core 후보 커버리지

2026-10-18의 source-mask/segmentation 준비에는 800개 target coadd에서
형태학적으로 compact한 후보 8,078개가 저장되어 있다. 새 요약기
`summarize_psf_candidate_coverage.py`가 독립 artifact audit의 표 해시를 다시
확인하고, 800개 후보 표를 모두 검증했다. 731개 프레임은 compact 후보가 4개
이상이고, 2개 프레임은 후보가 없다. i 필터는 309개 중 274개가 4개 이상,
i2 필터는 491개 중 457개가 4개 이상이다. 후보 테이블은 모두
`provisional_compact_candidate`로 표시된다. 프레임별 moment-FWHM 중앙값의
중앙값은 i 5.26픽셀, i2 5.63픽셀이지만, 이는 PSF 적합이나 seeing 승인값이 아니다.

이 후보는 target/coadd 영상 내부의 morphology 컷으로 선택됐으며 compact galaxy
혼입 가능성이 있다. 101×101픽셀 우표의 유효 최대 반경은 50픽셀뿐이어서 ICL

국소 stellar PSF 모델 또는 PSF 보정 승인을 뜻하지 않는다. 해시 검증을 포함한
요약은 `/gpfs/kjhan/Astrafek/data/sample_800_2026-10-13/psf_candidate_coverage_2026-10-19_01/summary.json`에
있으며 `science_measurement=false`, `psf_approved=false`를 유지한다.

### Gaia 근거 확장을 위한 오프라인 요청 계획

기존 Gaia DR3 위치 대조는 569개 후보 위치에 73개 source 행을 반환했고,
후속 영상 진단에서 네 마스크/배경 조합을 모두 통과한 별은 4개뿐이었다.
따라서 800개 영상에서 얻은 전체 8,078개 morphology 후보 중 이전에 조회하지
않은 7,509개 위치의 2초각 Gaia DR3 대조 계획을 Astrafek
[`prepare_psf_gaia_full_sample_plan.py`](prepare_psf_gaia_full_sample_plan.py)로
오프라인 생성했다. 이전 Gaia 요청과 같은 18개 astrometry·품질·변광·분류 열만
요청하며 HSC 영상, shape 행, photo-z는 포함하지 않는다.

계획은 748개 프레임의 새 후보를 포함하고 이전 요청 50개 프레임과 합쳐 798/800
프레임에 후보를 둔다. 계획 당시 업로드 좌표 VOTable은 815,917바이트였고 기존
대조 행률의 단순 외삽 응답은 약 963행/0.20 MB였다. 2026-10-20 사용자 승인 뒤
ESA Gaia DR3 TAP 조회를 완료했다. 업로드 조인은 7,509개와 250개 시험 배치 모두
서버에서 약 60초 후 중단되어, 동일한 2초각 원뿔을 250개씩 ADQL에 넣는 31개
직렬 조회로 전환했다. TAP은 승인된 16개 Gaia 열만 반환했고, Astrafek이 각
응답원을 원래 후보에 정확히 연결해 최종 18개 열을 만들었다. 이미지·HSC shape·
photo-z는 요청하지 않았다.

`8b0bb74973a003bea6b1efe673fbb37a755743f76d6dbf3b027505441bc0489a`, ADQL SHA-256은
`488b7c71c209da3bf3487f4c0c8b4d2210f8ddb329d24af8dc8544c5c917d4db`다. 승인 계획은
`/gpfs/kjhan/Astrafek/data/sample_800_2026-10-13/psf_gaia_full_sample_plan_2026-10-20_01/plan.json`

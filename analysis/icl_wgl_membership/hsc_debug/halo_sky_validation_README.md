# 위성 외곽 크기·하늘 제약의 공동 검증

2026-10-13. 이전 [주입/회수 실험](neighbor_injection_README.md)의 후속이다.
**외곽 크기와 하늘 곡률을 함께 적합하면 지정한 모형 오차는 줄어들지만,
국소 하늘 잔차·PSF 오차·가림 문제까지 해결되지는 않았다.** 관측 스태킹의
과학 승인 조건을 충족했다는 결과가 아니다.

## 재현 조건

이전 실험의 저장 입력 `neighbor_injection_2026-10-13_01/inputs/<ID>.npz`를
해시 검사 후 읽었다. 5724·619·5814·5104·3505의 면적 집합과 6940의 마스크
스트레스 조건을 분리했다. 실제 HSC에서 얻은 것은 분산·마스크·위치·거리 척도다.
science 픽셀은 합성이며, 모든 비교 방법은 같은 품질 마스크와 잡음을 사용한다.
이번에는 SEP 검출/마스크 방법을 다시 비교하지 않았다.

각 조건의 지수형 BCG/확산/이웃 중심 형태와 크기, 알려진 위치, 좁은 Gaussian
PSF는 이전 가정을 유지했다. 단위는 원래 픽셀잡음 sigma로 정규화한 유한
321×321 우표 내 적분 진폭이다. 35 kpc 확산 척도 등을 관측으로 추정한 것이 아니다.
이웃 최대 3개, 확산 진폭 1500/4500, 이웃별 외곽 진폭 0/500/1000을 사용한다.

6개 영상 조건 × 8개 생성 조건 × 3개 잡음 seed × 2×3 진폭 = **864장면**이다.
방법 5개로 **4320개 회수 기록**, 크기별 적합 **25,056건**을 저장했다.
영상 조건마다 잡음 3개를 진폭·생성 조건·방법 사이에 공유하므로 864개 독립
잡음 실현이 아니다. 하늘 외부 측정의 별도 seed도 같은 방식으로 공유한다.

## 비교 방법과 실패 처리

| 방법 | 이웃 외곽 크기 | 하늘 |
|---|---|---|
| `fixed8_plane` | 8 kpc 고정 | 상수+x+y: 이전 기준 모형 |
| `grid_plane` | 공통 크기 4–16 kpc, 2 kpc 간격 | 상수+x+y |
| `grid_quadratic` | 같은 격자 | 상수+x+y+x²+xy+y² |
| `grid_sky_anchor` | 같은 격자 | 이차식 + 독립 합성 하늘 측정 |
| `grid_biased_anchor` | 같은 격자 | 위와 같지만 외부 곡률 측정에 편향 추가 |

각 격자점에서 분산 가중 선형 적합을 수행한다. 성분 진폭은 음수를 허용한다.
전체 이웃의 **공통** 크기를 이미지와 하늘 측정의 결합 chi-square 최솟값으로
선택하며 주입 참값으로 크기를 고르지 않는다. 형태·위치·확산 척도는 고정이고
연속적인 형태 최적화나 이웃별 독립 크기 추정은 아니다.

하늘 좌표 x/y는 중심으로부터의 픽셀 거리를 160.5로 나눈 값이며 이차항은 전체
우표 평균을 뺐다. 외부 하늘 측정은 여섯 계수 각각에 독립 Gaussian sigma=0.01을
주는 합성 관측값이다. 이미지 잡음과 별도 seed를 사용한다. 편향 조건은 x²와
y² 계수에 각각 +0.02(설정한 sigma의 2배)를 추가한다. 이는 실제 대조장에서 얻은
정밀도나 추천 사전분포가 아니다. 실제 대조장 영상은 아직 없으며 공간적 전달,
계수 간 공분산, 제약 강도 변화는 후속 검증 대상이다.

선택한 크기의 형식 공분산만 보고하지 않는다. 각 크기의 조건부 확산 진폭에 대해
`chi2_min(scale) + (D-Dhat(scale))² / Var(D|scale)`를 계산하고, 전체 최소에서
Delta-chi-square≤1인 구간들의 최솟값/최댓값을 기록한다. 이는 크기 모호성을
포함하는 **격자 안의 profile 구간 외피**다. 분리된 구간 사이의 빈틈을 포함할 수
있고, 격자 밖 크기·형태 오차는 포함하지 않으며, 보정된 68% 신뢰구간으로 부르지 않는다.
경계 선택 수, 지지되는 격자점 수, 조건부 공분산, 수치 실패를 함께 저장한다.

열 정규화와 조건수 검사를 유지했다. 원본 마스크를 풀지 않는다. 모형 성분의
우표 내 플럭스 중 보이는 비율이 1% 미만이면 `blocked_hidden_component`로 별도
기록한다. 이 조건을 넘겼다는 것만으로 과학적으로 사용 가능한 표본은 아니다.
외곽 진폭 0일 때는 외곽 크기의 식별 자체가 불가능하므로, 크기 경계/모호성 집계를
외곽 진폭 0인 경우와 양수인 경우로도 나눴다.

## 생성 조건

이전 네 조건(일치 모형, 실제 외곽 12 kpc, 합성 PSF 날개 누락, 이차 하늘 누락)을
그대로 재현하고 다음 네 조건을 추가했다.

- `extended_curved`: 실제 외곽 12 kpc와 하늘 곡률 0.05를 함께 주입.
- `off_grid_curved`: 격자에 없는 실제 외곽 10.5 kpc와 같은 곡률.
- `heterogeneous_curved`: 이웃 순서별 외곽 6/11/16 kpc와 같은 곡률.
  이웃이 하나뿐인 619·5814에서는 6 kpc 하나이므로 이질성 시험이 아니다.
- `unmodeled_sky`: 이차 하늘 위에 중심에서 벗어난 넓은 Gaussian 잔차
  `0.06*(exp(-((x-.15)²+(y+.1)²)/(2*.3²))-전체평균)`를 추가.
  이 국소 성분은 적합 다항식과 합성 대조 측정에 모두 없다. 확산광과 혼동되기 쉬운
  의도적인 실패 시험이며 실제 HSC 하늘 잔차 분포를 재현했다는 주장은 아니다.

이 조건에서 이웃 외곽 주입량에 대한 확산 회수량의 기울기 중앙값은 고정 모형
0.501에서 자유 이차 하늘 0.010, 합성 외부 제약 0.014로 줄었다. 완전한
진폭 6개 격자만 계산했다. 크기 선택이 포함된 비선형 응답을 선형 회귀로 요약한
값이며, 광자가 이동한 비율이나 물리적 상관이 아니다. 참값 조건별 평균을 제거한
오차 상관은 자유 이차 하늘 −0.355, 합성 제약 −0.594다. 외곽과 확산 성분의
공동 오차를 계속 처리해야 한다.

하늘 곡률을 포함하면 외곽 12 kpc 단독/곡률 동반 조건의 회수 오차가 같은 것은
추가된 진짜 곡률이 적합 기저에 있고 같은 잡음을 쓰기 때문이다. 독립된 재현
성공 두 번으로 세지 않는다. profile 구간의 참값 포함률도 외곽 12+곡률에서
자유 이차 하늘 60.0%, 합성 제약 64.4%지만 seed가 조건별 3개뿐이고 진폭 간
잡음이 공유되므로 신뢰수준을 검증한 수치가 아니다.

국소 하늘 잔차에서는 자유 이차 하늘/합성 제약의 절대 상대 오차 중앙값도 각각
36.44%/31.22%다. 외부 제약을 넣어 구간을 좁혀도 참값 포함률은 6.7%로 낮았다.
좋은 외부 제약이 있어도 과학 영상에만 존재하는 잔차는 제거하지 못한다.
PSF 날개 누락 역시 크기·하늘 자유도만으로 해결되지 않았다.

모든 4320개 기록과 25,056개 격자 적합은 수치적으로 성공했다. 그러나 6940의
720개 방법 기록은 모두 성분 가림으로 정보 부족을 표시했다. 외곽 12+곡률에서
자유 이차 하늘의 profile 반폭 중앙값은 약 6826, 합성 하늘 제약도 약 2433이다.
다른 다섯 조건과 통합하지 않았으며 과학 회수로 승인하지 않는다.

## 실행·검증·산출물

lageunha CPU, BLAS/OMP/MKL 각각 1 thread, `MPLBACKEND=Agg`에서 실행했다.
사전 실행 48장면은 `halo_sky_preflight_2026-10-13_01`, 최종 실행은 다음 경로다.

```text
/gpfs/kjhan/Astrafek/data/sample_800_2026-10-13/halo_sky_validation_2026-10-13_01
```

계산 약 19.2초. 기존 5건+신규 6건, 총 **11개 테스트 통과**. 신규 검사는 독립
증강행렬 SVD와의 계수/공분산/잔차 비교, 무잡음 참값 회수, 잘못된 하늘 제약,
크기 모호성 구간, 특이행렬·가림 실패, 정보 부족 표시, 부호·분산 배율을 다룬다.
초기 테스트에서 하늘 항만 있는 입력의 빈 소스 목록 처리가 빠진 것을 확인해 수정했다.

입력·코드 해시, 전체 격자/seed/실패 기록, profile 구간 감사를 통과했다.
이전 기준 **432건**의 확산광을 재현했고 최대 절대 차이는 **1.93e-10**이다.
선택한 크기에서 별도 열 정규화 SVD로 **60건**을 검산했다. 계수·합계 외곽광·
확산광 공분산·직접 잔차 chi-square가 일치하며, 확산광 최대 절대 차이 **3.23e-9**다.
60건은 각 사례×일치/외곽12+곡률×5방법의 마지막 seed·높은 진폭 조합이다.
모든 25,056건을 독립 재계산한 것으로 확대하지 않는다.

재현 명령은 OGFinder 루트에서 다음과 같다. 실행 폴더는 새 경로를 지정한다.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 MPLBACKEND=Agg \
python3 analysis/icl_wgl_membership/hsc_debug/validate_halo_sky.py \
  --previous /gpfs/kjhan/Astrafek/data/sample_800_2026-10-13/neighbor_injection_2026-10-13_01 \
  --work /gpfs/kjhan/Astrafek/data/sample_800_2026-10-13/halo_sky_validation_NEW

OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 MPLBACKEND=Agg \
python3 analysis/icl_wgl_membership/hsc_debug/audit_halo_sky.py \
  --work /gpfs/kjhan/Astrafek/data/sample_800_2026-10-13/halo_sky_validation_NEW
```

`summary.json`, `recovery.tsv`, `scale_profiles.tsv`, `cohort_report.json`,
`artifact_audit.json`, `halo_sky_comparison.png`를 저장했다.
외곽 진폭 0/양수의 경계 선택·모호성 집계를 추가한 최종 감사 보고서와 그림은
같은 결과 폴더의 `audit_02/`에 있다. 첫 감사 파일을 덮어쓰지 않았다. 기존 결과의
재감사에는 `audit_halo_sky.py --work <결과> --output <새 감사 폴더>`를 사용한다.
`science_measurement=false`, `observational_validation_passed=false`를 유지했다.
원본 FITS·기존 산출물·활성 manifest 변경, 새 인증·다운로드, 관측 스태킹,
커밋·푸시는 하지 않았다.

## 후속 판단

외곽 크기와 하늘을 공동 제약하는 방향은 유지하되, 다음 검증 전에는 관측 관계를
과학 결과로 해석하지 않는다. 우선 이미 확보한 random 좌표/patch QA로 대조장
선정 조건을 명시하고, 실제 영상의 대조장 일치도와 하늘 공간 변동을 측정해야 한다.
외부 제약의 정밀도·상관·편향은 그 결과에서 정한다. 경험적 PSF 날개와 상관잡음,
미검출 소스도 주입 회수에 넣어야 한다. 이후 크기 격자 경계/간격과 이웃별 크기,
확산 형태 변화 및 더 많은 독립 잡음 실현으로 불확실성 포함률을 검증한다.
800장 전체를 바로 스태킹하는 단계로 넘기지 않는다.

2026-10-14 후속: 공식 목록의 잠정 대조 좌표와 실제 50장 영상의 외곽 잔차를
[control_sky_README.md](control_sky_README.md)에 기록했다. 실제 대조장 영상에
기반한 하늘 제약과 경험적 PSF 검증은 계속 남아 있다.

# 대조장 좌표 선정과 관측 외곽 잔차 진단

후속 진행: [공식 patch 연결·경험적 PSF 진단](patch_psf_README.md)에서 QA 대용값을
공개 경계 연결로 갱신하고 798개 대조장 실행 입력을 준비했다. 이후
[798장 다운로드·전체 픽셀 검사와 50쌍 외곽 비교](control_images_README.md)를 완료했다.
아래 787개와 대조장 영상 0개 기록은 이전 단계의 결과이며 과학용 보정 승인은 남아 있다.

2026-10-14. [외곽 크기·하늘 제약 합성 실험](halo_sky_validation_README.md)의
후속으로, 확보된 공식 random 목록에서 잠정 대조장 좌표를 만들고 실제 검증
영상 50장의 외곽 잔차를 조사했다. **대조장 영상의 하늘 보정이나 관측 ICL
측정을 완료한 것은 아니다.** 새 인증을 요청하지 않았고 원본 영상·활성 manifest는 보존했다.

## 공식 목록에서 사용할 수 있는 정보

[HSC PDR3 random 설명](https://hsc-release.mtk.nao.ac.jp/doc/index.php/random-points__pdr3/)에서
`sky_mean`과 `sky_std`는 patch 안에서 일정한 2초각 직경 sky-object 구경 통계라고
명시한다. 이 값으로 현재 `coadd/bg` 영상의 픽셀별 국소 하늘이나 큰 척도의
곡률을 대체하지 않았다. [공식 데이터베이스 설명](https://hsc-release.mtk.nao.ac.jp/doc/index.php/database__pdr3/)의
`patch_qa`는 patch 평균 깊이·시상 정보로 사용했다.

완료된 CSV의 SHA-256과 행 수를 검사한 뒤 random 160,000행과 patch QA 56,994행을
읽었다. random의 고유 object ID는 109,402개다. 서로 겹치는 검색 영역의 동일
좌표가 여러 대상에 나타날 수 있으므로 160,000행을 독립 대조장으로 세지 않는다.
원래 조회는 대상당 30각분 안의 해시 순서 최대 200개이며, 면적에 대해 편향 없는
표본 또는 마스크 면적 산정용 전체 random 표본이 아니다.

## 잠정 대조장 선정

`prepare_control_candidates.py`는 다음 규칙을 적용했다.

1. primary·patch-inner·tract-inner가 명시적으로 true인지 확인한다. i-band의
   edge/off-image/bad/interpolated/saturated/CR/suspect/bright-object와 입력 수
   관련 실패 플래그는 명시적으로 false여야 한다. 입력 수와 픽셀 분산은 양수여야
   한다. 빈 값·알 수 없는 값은 통과시키지 않는다.
2. patch QA에 i-band 영상 존재와 유한한 양의 깊이·시상이 있어야 한다.
3. 대상 좌표 5각분 이내의 가장 가까운 유효 random 지점의 patch QA를 **근방 대용값**으로
   삼는다. 영상 헤더에 tract/patch 식별자가 없어 정확한 대상 patch 일치를 확인한
   것이 아니다. 후보의 깊이 차이≤0.3 mag, 시상 비율 1/1.2–1.2,
   SFD E(B−V) 차이≤0.02를 잠정 조건으로 쓴다. 이 문턱들은 이번 기술 검증의
   명시적 선택이며 과학적 완전성 조건으로 검증된 값이 아니다.
4. SFD 지도의 기존 해시를 확인하고 각 대조 좌표의 E(B−V)를 직접 조회한다.
   실제 유효 passband 검증·광량 소광 보정은 적용하지 않는다.
5. 현재 보유한 별마스크 적용 S20A CAMIRA **7,319개 전체**와 비교한다. 선택한 800개나
   같은 적색편이 구간만 배제하지 않는다. 각 CAMIRA 광학 적색편이로 0.5/1/2 Mpc의
   각반경을 계산한다. 이는 고정 물리 배제 반경이며 R200·질량 추정이 아니다.
6. 중심만 배제하지 않고, 요청 정사각형 영상의 반대각선에 1초각 여유를 더한 구면
   원을 사용한다. 이 원과 은하단 배제 원이 닿는 후보도 제거한다. 보수적인 원
   근사이므로 실제 정사각형끼리는 겹치지 않는 후보를 추가로 버릴 수 있다.
7. 후보가 적은 대상부터 깊이·시상·소광 차이 점수가 작은 좌표를 고른다.
   대상당 한 개, object ID 중복 금지, 대조장 원끼리 겹침 금지다. 이 greedy 배정은
   최대 배정 수 최적화나 관측 배경의 통계적 독립성을 보증하지 않는다.

| 은하단 배제 반경 | 잠정 조건을 만족한 후보 행 | 후보가 있는 대상 | 겹치지 않게 배정된 좌표 |
|---|---:|---:|---:|
| 0.5 Mpc | 75,587 | 787 | 787 |
| 1.0 Mpc | 63,094 | 787 | 787 |
| 2.0 Mpc | 38,952 | 787 | 787 |

13개 대상은 5각분 안의 유효 근방 품질 대용값을 확보하지 못했다. 문턱을 임의로
늘려 채우지 않았다. 반경별 배정 수가 같아도 좌표가 같거나 환경 선택 편향이
없다는 뜻은 아니다. 기준 1 Mpc 배정에 대해 0.5 Mpc에서는 316개, 2 Mpc에서는
505개의 좌표가 바뀐다. 보수적인 영상 원을 사용한 뒤에도 가장 가까운 은하단
배제 원과의 여유는 1 Mpc 기준 약 0.007초각이다. 카탈로그 중심 위치와
물리 배제 반경의 불확실성까지 고려한 안전 여유가 검증됐다는 뜻은 아니다.
고정한 카탈로그는 별마스크·검출 한계를 가진 목록이므로 모든 실제 은하단과의
겹침을 제거했다고 주장하지 않는다.

기본 1 Mpc 조건의 787개 좌표는 `request_plan.json`의 **잠정 요청 계획**이다.
다운로드 실행용 확정 manifest로 등록하지 않았다. 정확한 대상 patch 대응,
대조장 영상 전체의 i-band coverage/필터·품질 마스크·유효면적, 경험적 PSF·깊이,
대조장별 소광·배경 공분산 검증은 남아 있다. 실제 대조장 영상 다운로드 수는 0,
과학용으로 승인한 대조장은 0이다.

## 관측 영상의 외곽 잔차

`diagnose_outer_sky.py`는 기존 40개 면적 집합과 10개 마스크 스트레스 영상의
600–900 kpc 고리를 검사한다. 이 영역에도 은하단 외곽광·PSF 날개·cirrus·미검출
천체가 남을 수 있으므로 blank sky로 간주하지 않는다. 원본 FITS와 기존 검토용
마스크의 해시·WCS·기본 품질 마스크 보존·Kron 2.5/3.5/5.0 마스크의 포함 관계를 확인했다.

64×64픽셀 타일을 사용하고, 고리 안 픽셀 128개 이상, 유효 픽셀 128개 이상이며
유효 비율≥50%인 타일만 통계에 사용한다. 원본 픽셀의 평균·중앙값과
`sqrt(sum(variance))/N`의 명목 평균 오차를 저장한다. 타일 평균에 가중 평면을
적합한 잔차의 `1.4826×MAD`를 명목 타일 평균 오차 중앙값과 비교한다.
이 평면과 잔차를 원본 science 영상에서 빼지 않는다.

같은 타일 안에서만 1/2/4/8픽셀 간격의 x/y 픽셀쌍도 검사했다. 타일 중앙값을
뺀 픽셀을 각 픽셀 분산의 제곱근으로 나누고 상관과 공분산을 기록한다.
패딩·주기 경계나 서로 다른 타일 사이의 쌍은 사용하지 않는다. 이 상관에는
남은 천체 구조와 선택 마스크의 영향도 포함되므로 순수 coadd 잡음 커널이 아니다.

50장×3마스크=150개 진단, 26,906개 타일 기록, 1,200개 간격/방향별 상관 기록을
완료했고, 모두 유효 타일 10개 이상을 확보했다.
다음은 영상별 통계의 중앙값이다. 마스크마다 살아남는 타일 집합이 달라지므로
행 간 감소를 소스 날개 제거의 인과 효과로만 해석하지 않는다.

| 집합 | Kron | 외곽 유효면적 | 타일 잔차 MAD / 명목 평균 오차 |
|---|---:|---:|---:|
| 면적 집합 40장 | 2.5 | 약 44.7% | 약 2.79 |
| 면적 집합 40장 | 3.5 | 약 37.3% | 약 2.58 |
| 면적 집합 40장 | 5.0 | 약 26.0% | 약 2.41 |
| 스트레스 10장 | 2.5 | 약 41.6% | 약 3.15 |
| 스트레스 10장 | 3.5 | 약 35.7% | 약 2.85 |
| 스트레스 10장 | 5.0 | 약 25.4% | 약 2.57 |

1픽셀 상관은 두 집합에서 대략 0.054–0.055다. 타일 잔차의 큰 척도 산포는
명목 독립 픽셀 분산보다 크지만, 위 2.4–3.2를 최종 오차 보정 배율로 바로
사용하지 않는다. 실제 대조장과 동일한 마스크·첨도/소스 잔차·공간 공분산을
비교해야 한다. 외곽 면적 진단을 중심 0–500 kpc의 측정 승인으로 대신하지 않는다.

## 독립 검증과 재현

신규 테스트 8건은 RA 경계·극점, 중심 밖에서 겹치는 영상 footprint, 더 멀지만
각반경이 큰 은하단, 알 수 없는 품질값 차단, 고유·비중첩 배정, 평면 회수,
가린 극단값 배제, 독립/상관 잡음 구분, 비어 있는 측정 및 명목 분산을 검사한다.
계산은 lageunha CPU에서 BLAS/OMP/MKL 각각 1 thread로 실행했다.

최초 외곽 진단은 기존 `ogfkit.wlcluster.Cosmology`의 512점 거리 보간을 사용했다.
독립 Astropy 계산과 거리가 약 0.002–0.005% 달라 여섯 검산 사례의 일부 고리
경계 픽셀 수가 어긋났다. 이번 외곽 진단만 Astropy `FlatLambdaCDM(H0=70, Om0=.3,
Tcmb0=0)`로 통일하고 `..._02`에 재실행했다. 기존 공용 코어·과거 주입 결과·첫
진단은 변경하지 않았다. 이는 실험 간 동일한 거리 정의가 필요함을 확인한 수정이다.

`audit_control_sky.py`는 모든 사용 입력 해시와 후보·진단 격자를 확인한다.
선택된 대조장을 Astropy의 독립 천구 거리 계산으로 모든 CAMIRA 및 다른 대조장과
재대조한다. 원본 science/분산/마스크에서 이전 주입 실험의 6개 사례×3마스크×
첫/중간/마지막 타일을 재계산해 픽셀 수·평균·명목 오차를 대조한다.

최종 감사는 **입력 해시 190건, 반경별 787개씩의 전체 CAMIRA/대조장 겹침 검사,
독립 타일 재계산 54건**을 통과했다. 타일 평균 최대 절대 차이는 0이었다.
대조장 후보 준비 약 24.0초, 최종 관측 외곽 진단 약 23.3초였다.

상위 경로는 `/gpfs/kjhan/Astrafek/data/sample_800_2026-10-13`이다.

- `control_candidates_2026-10-14_01`: 후보 감사표, 대상 QA 대용값, 반경별 잠정
  좌표 표, 기본 `request_plan.json`, 입력 해시와 설정을 포함한 `summary.json`.
- `outer_sky_diagnostics_2026-10-14_02`: 최종 `tile_stats.tsv`, `frame_stats.tsv`,
  `lag_products.tsv`, `summary.json`, `outer_residuals.png`.
- `control_sky_audit_2026-10-14_02/audit.json`: 최종 독립 감사.
- 외곽 진단 `_01`과 미완료 첫 감사 `_01`은 이력으로 보존한다.

OGFinder 루트에서 재실행하며, 출력 경로는 존재하지 않는 새 폴더여야 한다.
다음 명령은 lageunha에서만 실행한다.

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 MPLBACKEND=Agg
python3 analysis/icl_wgl_membership/hsc_debug/prepare_control_candidates.py \
  --sample /gpfs/kjhan/Astrafek/data/sample_800_2026-10-13 --work /gpfs/kjhan/Astrafek/data/control_NEW
python3 analysis/icl_wgl_membership/hsc_debug/diagnose_outer_sky.py \
  --sample /gpfs/kjhan/Astrafek/data/sample_800_2026-10-13 --work /gpfs/kjhan/Astrafek/data/outer_sky_NEW
python3 analysis/icl_wgl_membership/hsc_debug/audit_control_sky.py \
  --controls /gpfs/kjhan/Astrafek/data/control_NEW --sky /gpfs/kjhan/Astrafek/data/outer_sky_NEW \
  --work /gpfs/kjhan/Astrafek/data/control_sky_audit_NEW
```

과학 승인 상태는 계속 false다. 다음은 정확한 대상 patch 연결과 대조장 전체 영상
검증, 경험적 PSF 날개, 같은 유효 타일을 이용한 마스크 비교 및 독립 대조장
공분산 검증이다. 이번 잔차 통계를 합성 실험의 하늘 사전정보로 곧바로 편입하지 않는다.

# Continuous ICL–weak-lensing relation (2026-11-06)

## Analysis

Astrafek revalidated the already approved local HSC source and random-center
exports and selected the exact 70 i2 lenses in the ICL/WL common-support audit.
For each lens it stacked the HSC-Y3-calibrated `DeltaSigma` profile from the
cluster position, subtracted the pooled profile of that lens's five matched
random centers, and regressed each radial-bin tangential and cross component
on continuous target-minus-control ICL surface brightness at 200–300 kpc. The
model includes standardized redshift and log richness as linear covariates.
The ICL predictor has standard deviation 6.285 nJy arcsec⁻² in this sample.
Source tomography bins 2–4 and proper radial bins from 0.1 to 3 Mpc were used.

The Astrafek runner is
[`analyze_wl_continuous_icl_relation.py`](analyze_wl_continuous_icl_relation.py).
It recalculates a shared 5-degree equal-area delete-one-block covariance for
the regression slopes while deleting source and lens/center rows together.
There are 27 occupied approximate cells. Radial support varies: the full
sample contributing to successive bins is 58, 63, 65, 66, 67, 68, and 70
lenses; block deletions can reduce a bin's support further. The block errors
are therefore sensitivity estimates under this approximate partition, not a
validated HSC-field covariance.

## Results

Slopes below are the change in random-subtracted `DeltaSigma` per 1-SD higher
ICL contrast. Errors shown are the approximate spatial delete-one-block
errors; the nominal p column uses the lens-level HC3 covariance.

| R (proper Mpc) | N lenses | Tangential slope (10¹² M☉ Mpc⁻²) | Block error | HC3 nominal p |
|---:|---:|---:|---:|---:|
| 0.1–0.2 | 58 | −112.2 | 57.5 | 0.117 |
| 0.2–0.4 | 63 | −11.2 | 18.6 | 0.697 |
| 0.4–0.7 | 65 | +20.6 | 13.4 | 0.123 |
| 0.7–1.0 | 66 | −3.6 | 10.4 | 0.711 |
| 1.0–1.5 | 67 | −1.3 | 8.6 | 0.858 |
| 1.5–2.0 | 68 | −10.2 | 7.9 | 0.198 |
| 2.0–3.0 | 70 | −12.3 | 4.8 | 0.021 |

Only the outermost bin has a nominal HC3 p below 0.05. Correcting the seven
tangential-bin tests gives a minimum Bonferroni/BH-adjusted value of 0.149;
no radial bin remains significant. Cross-component ICL slopes are consistent
with zero in all seven bins (all nominal p ≥ 0.20). The tangential profile
changes sign with radius and the outer negative slope is not reproduced by the
previous i2 median-split analysis. This does not establish an ICL–halo-mass
relation.

## Limits and gate

This is a conditional association within 70 of the 800 parent clusters, not a
measurement for the full parent sample. The selected ICL annulus still lacks
pixel-specific coadd weights and a physical injected-source Poisson
correction. The weak-lensing errors omit calibrated HSC field regions,
photo-z posterior uncertainty, residual shear calibration, reduced shear,
magnification, miscentering, and spatially varying depth/mask/PSF effects.
The fitted linear controls do not remove all mass, environment, or selection
differences. The outer-bin nominal result is exploratory and fails the
within-profile multiple-testing correction. Keep `science_measurement=false`.

No HSC query or image-pixel read was made for this analysis; only previously
approved local source rows and saved random-center rows were used.

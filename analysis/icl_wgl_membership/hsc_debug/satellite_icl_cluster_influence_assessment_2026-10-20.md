# ICL–위성 관계의 단일 은하단 영향도 — 2026-10-20

검증된 기존 94개 cluster/filter 행에서 적색이동과 풍부도를 통제한 200–300 kpc ICL 대 50–75 kpc 위성광 부분 Pearson 상관을 계산한 뒤, 각 필터 안에서 은하단 하나씩 제외해 다시 적합했다. 표본이나 변수를 재선택하지 않았고 신뢰구간이나 가설검정을 계산하지 않았다.

추가로 두 광도 측정값과 redshift·richness를 각각 순위화하고, 순위공간에서 redshift·richness의 선형 효과를 제거한 부분 Spearman 민감도를 계산했다. 이는 기존 보고서의 비보정 Spearman과 다른 보조 기술량이며 유의도 검정은 하지 않았다.

| 선택 / 필터 | 표본 r | 단일 은하단 제외 범위 | 부호 변경 |
|---|---:|---:|---:|
| 전체 지원 / i2 (68) | 0.2926 | 0.1510–0.3385 | 없음 |
| 전체 지원 / i (26) | 0.0790 | −0.0244–0.2991 | 1회 |
| 중심 적격 / i2 (15) | 0.3067 | 0.2538–0.4329 | 없음 |
| 중심 적격 / i (8) | −0.4212 | −0.7867–−0.1824 | 없음 |

i2 전체 지원 표본은 한 점만으로 부호가 결정되지는 않지만, 그 크기는 특정 표본 구성에 따라 달라진다. 전체 지원 표본에서 가장 영향력이 큰 ID 223은 자동 중심 후보가 유일하지 않거나 중심 마스크 조건을 통과하지 못해 더 엄격한 중심 적격 표본에는 포함되지 않는다. 중심 적격 i2 15개에서도 leave-one-out 부호는 유지되지만, 기존 5° 공간 블록 구간 `[-0.059, 0.812]`은 넓고 0을 포함한다. i 전체 지원 표본은 단일 은하단 삭제에서 부호가 한 번 바뀐다. 중심 적격 i 8개는 leave-one-out 결과가 모두 음수여도 기존 공간 블록 구간 `[-1, 1]`로 매우 불확실하다. 어느 부분표본도 검출 근거가 아니다. ID 223, 5382, 5476, 6762, 859는 이 선택된 표본에서의 영향점이지 물리적 이상치 판정이 아니다.

순위공간 부분상관은 전체 지원 i2에서 `0.139`(Pearson `0.293`), 전체 지원 i에서 `0.248`(Pearson `0.079`)였다. i의 전체 지원 부분 Pearson은 한 점 삭제에서 부호가 바뀌지만 부분 Spearman은 삭제 범위 `0.143–0.410`으로 부호가 유지됐다. 중심 적격 i2의 부분 Spearman은 `0.293`이고 삭제 범위 `0.186–0.448`이다. 중심 적격 i는 8개뿐이며 부분 Spearman `−0.513`의 삭제 범위가 `−0.640–0.286`으로 부호가 바뀐다. Pearson과 순위 결과의 차이, 선택별 부호 차이, 적은 표본 때문에 관계의 형태가 안정적이라고 결론내릴 수 없다.

# 공식 patch 경계 연결과 경험적 PSF 진단

후속: [공개 확장 PSF 확보·동일 배경 연산 비교](extended_psf_README.md)를 완료했다.
i-band FITS 두 개의 실제 다운로드, 관측 프로필 비교와 신호 추가 검산 결과는 해당 문서에 있다.
대조장 후속 상태는 [798장 전체 픽셀 검사와 50쌍 외곽 비교](control_images_README.md)에 있다.
아래 대조장 준비·검증 미완료 기록은 이 후속 단계 이전 상태다.

2026-10-14. [대조 좌표·외곽 잔차 준비](control_sky_README.md)의 후속 결과다.
**798개 대조장 다운로드 입력을 준비했고, Gaia 별 근거가 있는 32개의 실제
영상 프로필을 검토했다. 과학용 PSF와 대조장 영상의 검증은 아직 미완료다.**
모든 계산·테스트·그림 생성은 lageunha CPU에서 BLAS/OMP/MKL 각 1 thread로 수행했다.

## 대조장 좌표의 관측 구역 연결

[HSC PDR3 Available Data](https://hsc-release.mtk.nao.ac.jp/doc/index.php/available-data__pdr3/)에
공개된 W-AEGIS/hectomap/autumn/spring tract·patch 좌표 파일 4개를 확보했다.
원문 URL·바이트 수·SHA-256을 저장했다. 중복을 합친 고유 patch는 91,449개다.
`connect_control_patches.py`는 네 꼭짓점이 이루는 구면 다각형으로 좌표를 연결한다.
단순 RA 범위 비교 대신 단위벡터와 대원 변을 사용해 RA=0 경계도 처리한다.

이제 이전의 5각분 이내 random QA 대용값을 사용하지 않는다. 대상 800개 중
607개는 공개 경계 안에 사용 가능한 i-band patch가 하나이고, 192개는 여러 개다.
겹친 patch를 모두 보존하고, 대조 후보가 관련 **모든** patch의 깊이 차이≤0.3 mag,
시상 비율 1/1.2–1.2를 만족해야 한다. SFD E(B−V) 차이≤0.02와 이전의
중심 품질 플래그·전체 보유 CAMIRA 1 Mpc 배제·영상 영역 비중첩 조건을 유지한다.
이 문턱은 기술 검증의 선택이며 과학적 완전성 조건은 아니다.

중심 품질 조건을 통과한 random 114,654행 중 114,570행은 자신의 skymap patch
경계에도 들어간다. 나머지 84행은 제외했고 경계나 좌표를 자동 보정하지 않았다.
QA 중심 좌표가 있는 56,988개를 공개 patch 중심과 비교하면 최대 차이가
11.875초각이며, QA 중심이 비어 있는 6행은 비교 불가로 기록했다. 중심값의
일치를 경계 판정으로 대신하지 않았다. 실제 cutout의 primary tract 및 전체 영상
coverage는 아직 확인되지 않았으며 `selected_primary_tract_verified=false`다.

최종 좌표는 **798개**다. 이전 787개에 없던 13개가 추가되고 기존 2개가 제외됐다.
기존 대상의 배정 변경 249건에는 제외된 2건도 포함된다. 남은 대상은 다음과 같다.

| 대상 ID | 미배정 사유 |
|---|---|
| 1497 | 제공된 공개 patch 다각형에서 대상 좌표를 연결하지 못함 |
| 6470 | 겹친 4개 patch 모두와 화질 조건이 맞는 random 후보가 없음 |

두 경우를 영상 불량이나 관측 부재로 단정하지 않는다. 특히 경계 연결 실패는
정식 skymap/WCS로 검토할 항목이다. 조건을 느슨하게 해 숫자를 채우지 않았다.

독립 Astropy 천구 거리로 798개 모두를 CAMIRA 7,319개 및 다른 대조 영상과
재대조했다. 요청 영상의 반대각선+1초각 원과 CAMIRA 1 Mpc 원 사이 최소 여유는
약 0.00738초각, 대조장 원 사이 최소 여유는 약 0.1323초각이다. 카탈로그 중심과
배제 반경 불확실성에 대해 여유가 충분하다는 뜻은 아니다. 현재 CAMIRA 목록
밖의 미검출 은하단 및 큰 척도 환경 상관도 이 검사로 제거되지 않는다.

## 기존 다운로드 스크립트와 연결

`control_download_manifest.json`은 원래 성공한 `download_pilot.py`의 sample
형식을 사용한다. 전송 코드나 인증 방식을 새로 작성하지 않았다.
레거시 `clusters` 배열을 운송 형식으로 쓰지만, 최상위와 각 항목에
`frame_role=matched_control`, `bcg_policy=none`을 명시하고 대상 ID·random ID·좌표를
유지한다. 적색편이는 대응 은하단의 각척도를 정하는 값이며 대조장 자체의
물리적 적색편이가 아니다. 소광 보정·과학 승인 값은 미확정 상태로 둔다.

798개 science/mask/variance 영상의 추정 전송량은 **42.10 GiB**다.
입력 검사와 기존 다운로드 후 manifest 변환의 역할/좌표 보존 검사를 통과했다.
이는 실제 HTTP 전송 테스트가 아니다. 이번 작업에서 **새 대조 영상 0개**이며,
HSC 인증정보가 현재 프로세스에 남아 있지 않아 전송을 시작하지 않았다.
별도 인증 요청이나 암호 저장을 추가하지 않았다.

다음은 입력과 실행 경로를 기록한 명령이며 자동 실행한 명령은 아니다.
기존 인증을 처리하는 사용자 세션에서만 기존 다운로드 절차로 사용한다.
lageunha의 OGFinder 루트 기준이며 출력 폴더는 새 이름이어야 한다.

```bash
python3 analysis/icl_wgl_membership/hsc_debug/download_pilot.py \
  --manifest /gpfs/kjhan/Astrafek/data/sample_800_2026-10-13/control_patches_2026-10-14_02/control_download_manifest.json \
  --work /gpfs/kjhan/Astrafek/data/sample_800_2026-10-13/control_download_01 \
  --user kjhan0606
```

실제 영상 확보 후 필터·WCS·품질 마스크·전체 유효면적·깊이·PSF·배경을 검증해야 한다.
[HSC PDR3 FAQ](https://hsc-release.mtk.nao.ac.jp/doc/index.php/faq__pdr3/)에 따르면
`coadd/bg`에는 대응 카탈로그가 없고 카탈로그는 국소 하늘 제거 `calexp`에 기반한다.
따라서 patch QA와 random 목록의 sky 통계로 현재 영상의 잔차 검증을 대신하지 않는다.

## 실제 별 영상으로 본 PSF

`diagnose_empirical_psf.py`는 기존 Gaia 검토에서 별 근거를 충족한 32개,
23개 영상을 대상으로 한다. native HSC 검출 중심과 원본 픽셀을 사용하며
위치 보간·Gaia epoch 전파를 수행하지 않는다. 기존 101×101 우표보다 넓은
401×401픽셀(한 변 약 67.4초각)을 원본에서 잘랐다.

- 원본 품질·밝은별 비트는 유지한다. 목표 별 자신의 검출 마스크만 제외하고,
  다른 검출원의 segmentation과 Kron 2.5/3.5 타원을 가린다.
- 배경 구간은 120–150픽셀(20.16–25.20초각), 160–190픽셀(26.88–31.92초각)이다.
  유효 픽셀≥300, 전체 면적≥30%, 8방향 각각 픽셀≥20·면적≥25%를 요구한다.
  방향별 평균 8개의 평균을 배경 진단값으로 쓰며 clipping하지 않는다.
- 정규화는 반경 12픽셀(2.016초각) 안의 관측 광량이다. 중심부 유효면적≥99%,
  양의 광량, 대각 분산 기준 명목 S/N≥30을 요구한다. 총 PSF 광량으로 외삽하지 않는다.
- 0–96픽셀(0–16.128초각)의 11개 고리에 음수도 유지한 프로필을 기록한다.
  고리 면적≥50% 및 8방향 각각≥25%일 때 면적 조건을 통과한 것으로 표시한다.
  이 표시는 PSF 날개 검출이나 과학 승인 판정이 아니다.

마스크 2종×배경 2종×32개=128개 방법 기록의 결과는 다음과 같다.

| 상태 | 방법 기록 수 |
|---|---:|
| 진단 프로필 계산 가능 | 30 |
| 배경 구간 유효면적/방향 부족 | 49 |
| 401×401 우표가 원본 경계를 넘음 | 48 |
| 중심부 마스크 기준 미달 | 1 |

원본 우표는 20개 확보했고 12개는 영상 경계 때문에 제외됐다. 적어도 한 조건을
통과한 별은 **11개**, 네 조건을 모두 통과한 별은 **4개**다. 방사 기록은 330행이다.
네 조건을 통과한 별에서 배경 구간 변경에 따른 중심 광량 변화 절댓값의 중앙값은
약 0.0458%, 최대는 0.1120%다. 이는 좁은 중심 구경의 안정성이고 넓은 날개의
정확도는 아니다. 64–96픽셀(10.752–16.128초각) 고리에서 면적 조건을 통과한
25개 방법 기록 중 **23개는 배경 차감 평균이 0 이하**다. 같은 별의 반복 방법을
포함하므로 25개의 독립 별로 세지 않는다.

현재 결과로 양의 넓은 PSF 날개나 총광량 보정을 확정할 수 없다. 선택한 배경에
별의 날개·은하단 외곽광·미검출 천체가 포함될 수 있다. 음수 프로필을 0으로
자르거나 Gaussian으로 대체하지 않았다. 마스크를 바꾸면 사용 픽셀도 바뀌므로
두 마스크의 차이를 이웃 천체 제거 효과로만 해석하지 않는다.

`nominal_raw_mean_sigma`는 `sqrt(sum(variance))/N`이다. 배경·중심 정규화의
불확실성과 coadd 상관잡음을 포함한 오차가 아니다. 알려진 Gaia VARIABLE은
차단하도록 했지만 NOT_AVAILABLE은 비변광 확인을 뜻하지 않는다. Gaia 기준 epoch와
HSC coadd의 유효 epoch 대조도 남아 있다. 800개 은하단 전체에 공통 PSF를 만들지 않았다.

## 검증과 산출물

신규 테스트 **8건**이 통과했다. 공개 경계의 RA wrap/반대구/중복·누락 꼭짓점,
겹친 tract 보존, 기존 downloader의 control 역할 보존, 상수 배경 이동 불변성,
가린 중심·배경 차단, 배경 곡률에 따른 음수 날개, 가린 오염원 배제를 검사했다.

`audit_patch_psf.py` 최종 감사도 통과했다.

- 입력 SHA-256 80건, 공개 경계 원문 4개와 생성 스크립트 해시 확인.
- 별도 접평면 투영 후 다각형 판정 2,840건, 798개 전체 CAMIRA/대조장 구면 겹침 재검사.
- 실제 FITS에서 우표 20개의 science·variance·기본 품질·segmentation 재대조.
- SEP 호출 대신 회전 타원 수식으로 마스크 표본점 3,240건 검산.
- 배경·실패 조건과 방사 구간 330개 재계산. 원본 픽셀 평균의 최대 절대 차이는 0.

자료 상위 경로는 `/gpfs/kjhan/Astrafek/data/sample_800_2026-10-13`이다.

| 폴더 | 주요 산출물 |
|---|---|
| `control_patches_2026-10-14_02` | 공개 경계 원문, 대상 연결 표, 전체 후보 감사표, 798개 좌표, 실행용 manifest, summary |
| `empirical_psf_2026-10-14_01` | 별/실패 ledger, 20개 원본 우표 FITS, 방법·방사 표, 배경 민감도, `radial_review.png`, summary |
| `patch_psf_audit_2026-10-14_02` | 최종 `audit.json` |

최초 patch 실행 `_01`은 빈 QA 중심값 처리 중 중단됐고, 원문 4개는 보존해
최종 실행에서 재사용했다. 최초 감사 `_01`은 manifest의 마스크 참조 키가 달라
중단됐다. 다운로드 당시 기록의 실제 mask HDU를 사용해 `_02`에서 검산했다.
미완료 폴더와 이전 관측/합성 결과를 덮어쓰지 않았다.

다음은 대조장 실영상의 독립 배경·공분산 검사와 PSF 입력 보강이다. PSF는
영상 가장자리의 후보를 위한 더 넓은 영상, coadd epoch/위치·변광 검토,
영역별 공식 PSF 모형 및 실제 별 날개 비교가 필요하다. 밝은별 마스크를 임의로
해제해 표본을 늘리지 않는다. `science_measurement=false`, `psf_approved=false`,
`controls_ready_for_science=0`을 유지한다.

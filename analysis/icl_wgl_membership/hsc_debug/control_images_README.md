## 전체 798장 검사

`validate_control_images.py quality`는 기존 `hsc_quality.summarize_frame`을
재사용하고, 각 파일 전체 SHA-256을 다운로드 당시 기록과 다시 대조한다.

검사한 뒤 모든 science/variance/mask 픽셀을 읽는다.

유효 픽셀은 science가 유한하고 분산이 유한한 양수이며, 기존 품질 제외 비트와
BRIGHT_OBJECT 비트가 없는 픽셀이다. 0–500 kpc의 25 kpc 고리별 유효면적과
중심 10 kpc 마스크 상태를 기록한다. 중심은 random 좌표이며 BCG가 아니다.
고리의 50% 면적 문턱은 기술 진단용으로, 과학적 완전성이나 최종 채택 기준이 아니다.
이 단계에서는 새로 검출한 천체의 확장 마스크를 아직 적용하지 않는다.

기존 QA의 750–950 kpc 통계와 격자 통계도 보존한다. 여기서는 HSC DETECTED
비트만 추가로 제외하므로 이를 순수 하늘 배경으로 사용하지 않는다.
기존 함수의 단위 가정을 확인하여 instrumental_flux/pixel 입력만 허용한다.
반경은 최근 외곽 진단과 같은 Astropy FlatLambdaCDM(H0=70, Om0=0.3,
Tcmb0=0)으로 계산한다. 이전 800장 QA의 거리 근사 결과를 덮어쓰지 않는다.

## 50쌍 비교

`validate_control_images.py compare`는 기존 검증 표본의 은하단 ID로 대조장을
연결한다. 면적 조건 집합 40개와 마스크 스트레스 집합 10개를 구분하며,
800개 모집단을 대표하는 표본이라고 가정하지 않는다.

검출은 기존 SEP 설정(1.5σ, 최소 5픽셀, 32 deblend 단계, contrast 0.005)을
재사용한다. 검출용 배경은 science 영상에서 차감하지 않는다. 밝은별 비트는
검출 단계에서만 완화하고 최종 마스크에는 반드시 보존한다. 대조장에서는
random 중심의 천체까지 모든 검출 segmentation과 Kron 2.5/3.5/5.0 타원을
가린다. 품질 비트와 비유한 science/불량 분산 픽셀도 세 마스크에 모두 보존한다.

외곽 통계는 대응 은하단과 같은 600–900 kpc 영역, 64×64픽셀 타일,
고리 안 128픽셀 이상·유효 128픽셀 이상·유효 비율 50% 이상 기준을 적용한다.
타일 평균, 중앙값, `sqrt(sum(variance))/N`의 명목 평균 오차를 기록한다.
가중 평면 적합 잔차의 `1.4826×MAD`를 타일 명목 오차 중앙값으로 나눈다.
1/2/4/8픽셀 간격의 x/y 상관도 저장한다.

은하단 측 수치는 해시와 입력 조건을 확인한
`outer_sky_diagnostics_2026-10-14_02`의 기존 검산된 결과를 재사용한다.
은하단은 BCG 보존 및 멤버 위치 마스크가 추가되므로 두 역할의 마스크가 완전히
동일하지 않다. Kron 크기를 바꾸면 살아남는 픽셀·타일도 바뀐다.
따라서 잔차 감소를 천체 외곽광 제거의 인과 효과만으로 해석하지 않는다.

광량 비교는 원본 FLUXMAG0와 픽셀 면적으로 환산한 nJy/arcsec² 단위이며
소광과 유효 passband 보정 전이다. 헤더 i/i2가 같은 쌍을 별도 집계하지만,
헤더 일치가 실제 혼합 coadd의 유효 passband 일치까지 증명하지는 않는다.
은하단−대조장의 타일 평균 중앙값 차이는 배경 진단량이며 ICL 측정량이 아니다.

## 실행과 검산

프로젝트 `/home/kjhan/BACKUP/Astrafek/OGFinder`에서 다음 명령을 lageunha로
실행한다. 모든 출력 폴더는 새 이름이어야 한다. 원본 자료와 기존 결과는 보존한다.

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 MPLBACKEND=Agg
sample=/gpfs/kjhan/Astrafek/data/sample_800_2026-10-13
python3 analysis/icl_wgl_membership/hsc_debug/validate_control_images.py quality \
  --sample "$sample" --work "$sample/control_quality_2026-10-14_01"
python3 analysis/icl_wgl_membership/hsc_debug/validate_control_images.py compare \
  --sample "$sample" --quality "$sample/control_quality_2026-10-14_01" \
  --work "$sample/control_outer_2026-10-14_01"
python3 analysis/icl_wgl_membership/hsc_debug/audit_control_images.py \
  --sample "$sample" --quality "$sample/control_quality_2026-10-14_01" \
  --comparison "$sample/control_outer_2026-10-14_01" \
  --work "$sample/control_image_audit_2026-10-14_01"
python3 analysis/icl_wgl_membership/hsc_debug/plot_control_images.py \
  --comparison "$sample/control_outer_2026-10-14_01"
```

검산은 입력·마스크 해시, 모든 QA 레코드의 ID와 다운로드 해시 대응,
50장의 실제 품질 마스크와 세 확장 마스크 포함 관계, WCS, 반경별 유효면적,
각 방법의 첫/중간/마지막 타일 원본 통계와 단위 변환 후 차이를 재계산한다.
이 진단의 잔차와 상관에는 PSF 날개, 미검출 천체, cirrus, 은하단 외곽광이
남을 수 있다. 오차 배율이나 순수 잡음 커널로 승인하지 않는다.

`science_measurement=false`, `controls_ready_for_science=false`,
`sky_correction_approved=false`를 유지한다. 관측 주입 회수, PSF/배경 전달,
유효 passband·소광 검증과 최종 표본 선택은 후속 단계다.
